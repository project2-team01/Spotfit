## 1. 프로젝트 개요

### 주제

사용자의 금융 성향(금융 MBTI), 창업 예산, 위험 감수 성향을 상권 분석 결과와 결합합니다. 이를 통해 개인에게 맞는 창업 상권을 추천하고, 데이터 기반 창업 의사결정을 돕는 서비스를 만듭니다.

### 목표

1. 서울시 상권별 상업시설 구성과 업종 분포 분석
2. 상권별 매출, 경쟁 강도, 성장성, 안정성 분석
3. 분석 결과로 상권별 파생변수 생성
4. 상권별 창업 적합성 점수 산출
5. 금융 MBTI, 창업 예산, 위험 감수 성향에 따른 개인화 상권 추천

### 분석 범위

| 항목 | 계획 | 현재 상태 |
|---|---|---|
| 지역 | 서울특별시 | 같음 |
| 분석 단위 | 서울시 상권 × 업종 | 같음 |
| 분석 기간 | 2024~2025년 우선, 최신 데이터까지 확장 | **2025년만 수집됨** (7장 결정 필요 1번) |
| 분석 언어 | Python | 같음 |
| 주요 라이브러리 | Pandas, NumPy, GeoPandas, Matplotlib, Seaborn, Scikit-learn | STEP 1에는 Pandas, NumPy만 사용 |

### STEP 2. 데이터 전처리 및 결합 설계

소상공인 상가업소 정보와 서울시 상권분석 데이터를 통합하는 방법을 설계합니다.

필수 검토사항과 STEP 1에서 확인한 출발점:

| # | 검토사항 | ▶ STEP 1 결과 |
|---|---|---|
| 1 | 상권코드·업종코드 체계 확인 | 상권코드는 서울 데이터셋 사이 결합 키로 검증됨. 업종은 소상공인 247개, 서울 100개로 체계가 다름 |
| 2 | 업종 분류가 다를 때 매핑 테이블 설계 | 공식 연계표 없음. 직접 만들어야 함 |
| 3 | 위도·경도를 이용한 공간 조인 | 상가 좌표는 WGS84, 상권 경계는 EPSG:5181 |
| 4 | 서울시 상권 경계와 상가업소 좌표 매핑 | 상권 경계 1,650개 폴리곤 확보 |
| 5 | 기준연도·분기 정렬 | 서울은 분기 단위, 상가정보는 2025-12-31 스냅숏 |
| 6 | 결측치·이상치 처리 | 집객시설의 공백(0으로 추정), 개·폐업률 100 초과 값 확인 필요 |
| 7 | 중복 점포 처리 | 상가업소번호 중복 0건, 완전 중복 행 0건 |
| 8 | 현재 점포 데이터와 과거 매출 데이터의 시점 불일치 방지 | 상가정보 스냅숏을 어느 분기에 맞출지 결정 필요 |

최종 통합 분석 테이블에 들어갈 컬럼입니다. 각 컬럼의 출처, 계산 방법, 결합 기준을 STEP 2에서 확정합니다.

| 컬럼 | ▶ STEP 1에서 확인한 후보 원본 (확정 아님) |
|---|---|
| 기준연도, 기준분기 | 서울 데이터 `기준_년분기_코드` (예: 20251) |
| 상권코드, 상권명 | `상권_코드`, `상권_코드_명` |
| 업종코드, 업종명 | 서울 `서비스_업종_코드`, `서비스_업종_코드_명` |
| 추정매출액 | 추정매출 `당월_매출_금액` (이름과 달리 분기 매출) |
| 점포 수 | 점포 데이터 전체 점포 수, 또는 상가정보를 공간 조인해 센 값 |
| 유동인구 | 길단위인구 `총_유동인구_수` |
| 직장인구 | 직장인구 `총_직장_인구_수` |
| 상주인구 | 상주인구 `총_상주인구_수` |
| 집객시설 수 | 집객시설 `집객시설_수` (산정 기준 확인 필요) |
| 추가 파생변수 | STEP 3에서 정의 |

- 추정매출은 100개 업종 중 62개만 있습니다. 나머지 업종은 매출 칸이 비게 됩니다.

### STEP 3. 파생변수 설계

5개 분석 영역별로 변수를 설계합니다.

| 영역 | 변수 후보 |
|---|---|
| ① 상업시설 | 업종별 점포 수, 동일 업종 점포 밀집도, 상권 내 업종 다양성, 집객시설 밀집도, 특정 시설과 업종 간 연관성 |
| ② 매출 | 업종별 추정매출액, 점포당 평균 추정매출액, 전년 동기 대비 매출 성장률, 분기별 매출 변동성, 유동인구 대비 매출 효율 |
| ③ 경쟁 | 동일 업종 경쟁 점포 수, 단위 면적당 점포 수, 업종별 경쟁 집중도, 프랜차이즈 비중 |
| ④ 상권 안정성 | 폐업률, 개업률, 점포 수 증감률, 매출 변동성, 상권의 지속성 |
| ⑤ 수요 | 유동인구 대비 점포 수, 직장인구 비율, 상주인구 비율, 시간대별 인구 집중도, 연령대별 잠재 고객 비율 |

변수마다 아래 항목을 표로 정리합니다.

| 변수명 (영문 snake_case) | 설명 | 계산 공식 | 필요한 원본 컬럼 | 출처 | 분석 목적 | 해석 방법 | 확보 가능 여부 |
|---|---|---|---|---|---|---|---|

- 실제로 확보할 수 없는 데이터에 기대는 변수는 따로 표시합니다.
- ▶ STEP 1 결과: 아래 변수는 **2025년 자료만으로는 계산할 수 없거나 근거가 약합니다.**
  - 전년 동기 대비 매출 성장률: 2024년 자료가 필요합니다.
  - 연간 점포 수 증감률, 상권의 지속성: 여러 해의 자료가 필요합니다.
  - 분기별 매출 변동성: 2025년 4개 분기만으로는 표본이 작습니다.
- ▶ STEP 1 결과: 단위 면적당 점포 수에 쓸 상권 면적(`RELM_AR`)은 있습니다. 단위는 ㎡로 추정되며 확인이 필요합니다.

### STEP 4. 상권 점수화 모델 설계 (설계안)

5개 영역을 각각 0~100점으로 점수화합니다.

1. 매출 잠재력
2. 경쟁 위험
3. 상권 성장성
4. 상권 안정성
5. 입지 및 수요 적합성

설계안에 담을 내용:

- 점수 정규화 방법
- 이상치 처리 방식
- 동일 업종 안에서 상권을 비교하는 방식
- 지표별 가중치
- 점수 산출 공식
- 점수 해석 기준
- 점수화 근거와 한계

점수가 높을수록 창업에 유리하도록 방향을 통일합니다. 예를 들어 경쟁 위험은 위험이 낮을수록 점수가 높아야 합니다.

### STEP 5. 금융 MBTI 기반 개인화 추천 설계 (설계안)

입력값:

- 금융 MBTI
- 창업 예산
- 위험 감수 성향
- 희망 창업 업종

사용자 유형에 따라 상권 점수의 가중치를 다르게 적용합니다.

| 유형 예시 | 중요하게 보는 점수 |
|---|---|
| 안정형 | 상권 안정성, 경쟁 위험 |
| 성장형 | 매출 성장성, 수요 증가 가능성 |
| 공격형 | 높은 성장 잠재력에 더 큰 가중치 |

설계 조건:

- 금융 MBTI와 위험 감수 성향이 겹치는 경우 이중으로 반영하지 않습니다.
- 창업 예산은 점수 가중치가 아니라 **창업 가능 여부를 거르는 제약조건**으로 쓰는 방법도 제안합니다.
- 임대료·보증금·권리금·시설비 데이터가 부족하면 예산 적합성을 확정적으로 판단하지 않습니다. 추가 데이터가 필요하다고 명시합니다.
  - ▶ STEP 1 결과: 수집한 9개 데이터셋에는 임대료·보증금·권리금·시설비 컬럼이 없습니다.

## 5. 최종 산출물 구성

결과 문서는 다음 순서로 씁니다.

1. 프로젝트 데이터 분석 방향 요약
2. 수집 대상 데이터셋과 다운로드 링크
3. 데이터셋별 주요 컬럼 분석
4. 데이터 전처리와 결합 구조
5. 파생변수 정의서
6. 상권 점수화 모델 설계
7. 금융 MBTI 기반 개인화 추천 모델
8. EDA와 시각화 계획
9. Python 프로젝트 폴더 구조
10. 단계별 구현 로드맵

가능하면 Pandas와 GeoPandas 기반 데이터 결합 코드 예시도 포함합니다.

---

## 6. 작성 원칙

- 데이터 분석을 처음 배우는 사람도 이해할 수 있게 설명합니다.
- 실제 데이터로 구현할 수 있는 방법을 먼저 제안합니다.
- 확인되지 않은 데이터와 컬럼을 임의로 만들지 않습니다.
- 데이터 출처와 파생변수 계산 근거를 분명히 밝힙니다.
- 통계적 상관관계를 인과관계로 해석하지 않습니다.
- 복잡한 머신러닝보다 설명 가능한 규칙 기반 점수화 모델을 먼저 설계합니다.
- 발표에 쓸 수 있도록 분석 목적, 방법, 결과 해석까지 고려합니다.
- 기존 소비 통계 데이터가 있으면 재사용할 변수와 새 데이터로 바꿀 변수를 구분합니다.

진행 순서: **STEP 1~3은 상세히, STEP 4~6은 설계안으로 작성합니다.**

## 7. 결정이 필요한 사항

| # | 사항 | 배경 | 선택지 |
|---|---|---|---|
| 1 | 분석 기간 | 계획은 2024~2025년과 최신 자료입니다. 실제 수집은 2025년만 했습니다. 성장률·증감률 변수에는 2024년 자료가 필요합니다. 공식 출처에는 2026년 2분기 자료까지 있습니다 | 2025년 유지 / 2024년 추가 / 2026년까지 추가 |
| 2 | 상가정보 스냅숏과 분기 맞추기 | 상가정보는 2025-12-31 시점 하나입니다 | 2025년 4분기에 맞춤 / 분기별 스냅숏 추가 수집 |
| 3 | 업종 매핑 기준 | 소상공인 247개 업종과 서울 100개 업종을 잇는 공식 표가 없습니다 | 이름 기반 수작업 매핑 / 분석을 한쪽 체계로 통일 |
| 4 | 금융 MBTI 유형 정의 | 계획서에 유형 체계와 위험 감수 성향 문항 정의가 없습니다 | 팀에서 유형표 작성 |
