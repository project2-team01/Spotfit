## 3. 서울 상권 공간 단위 변경 이력과 기간 비교 가능성

공식 페이지 원문(K01·K02·K04~K07 공통, "2026. 7. 3. 적용"):

> 2024년부터 서울시 상권분석서비스의 공간 단위가 표준단위구역으로 변경되었습니다. 표준단위구역 기준 매출액 데이터는 카드사에서 2021년부터 제공하고 있어 데이터의 일관성 및 정확성 확보를 위해 2026년 7월 3일부터 2021년 이후 자료만 제공합니다.

확인한 사실:

1. 현재 포털과 API는 2021Q1 이후 자료만 제공합니다. 분기별 행 수로 확인했습니다.
2. 길단위인구의 분기당 상권 수가 2021Q1~2026Q2 내내 1,648~1,650입니다. 같은 1,650개 상권 체계로 제공되는 것으로 보입니다.
3. 연도별 ZIP 수정일이 모두 2026-07-03 이전입니다. 2021·2022년 ZIP은 2023-10-30, 영역 ZIP은 2023-10-23입니다.

비교 가능성 판단:

- 2021Q1~2026Q2는 같은 1,650개 상권 체계로 제공되는 것으로 보입니다. 분기별 상권 수가 일정합니다.
- (다운로드 후 확인) 2025년 범위에서는 다음을 검증했습니다.
  - 2025년 추정매출·점포 ZIP의 분기별 행 수가 현재 Open API 행 수와 4개 분기 모두 같습니다.
  - Open API 샘플 5행의 값이 ZIP 값과 같습니다.
  - 영역 ZIP의 상권코드 1,650개가 2025년 점포·유동인구 상권코드와 정확히 같습니다. 다른 데이터셋의 상권코드도 모두 이 안에 있습니다.
- 따라서 **2025년 자료끼리는 같은 상권 체계로 비교할 수 있습니다**. 2024년 이전 ZIP은 이번에 받지 않았으므로 검증하지 않았습니다.
- "표준단위구역"의 정의와 경계 자료를 설명하는 공지 원문은 찾지 못했습니다. 문의처는 서울신용보증재단 데이터분석팀(02-2174-5075)입니다.
