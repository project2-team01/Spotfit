## 검증과 검토 대상

런타임 검사 **268건**이 모두 통과했다. 테이블 갱신 저장에 따른 일부 반복 검사를 포함한 수이며, 서로 다른 검사 유형이 그만큼이라는 뜻은 아니다. [validation_checks.csv](qa/validation_checks.csv)에 개별 결과가 있다.

저장 파일 재검증에서도 분기별 원본 매출 합 보존, N:1 수요 결합의 행 수 보존, 0 분모·미관측 매출·전분기 부재의 결측 유지, 완전 연매출 조건, 공간 bridge의 전체 점포 ID 보존, 상대지수의 비교집단 조건을 확인했다. 결과는 [post_save_checks.json](qa/post_save_checks.json)에 있다.

연속 분기 중 점포 증감이 개업−폐업과 일치하지 않는 행이 **2,336개**다. 이것은 강제 보정하거나 삭제하지 않았다. 분류 변경·수집 정비 등의 가능성을 확인해야 한다. [stock_flow_mismatches.csv](qa/stock_flow_mismatches.csv)에 실제 차이와 키를 보존했다.

## 재실행과 파일 추적

`build_features.py`를 실행하면 데이터·QA·CSV 사전을 재생성한다. `verify_outputs.py`는 저장 파일 재검증 결과를 갱신한다. 설계 Markdown과 이 실행 요약은 자동 갱신하지 않으므로 데이터 범위·코드가 바뀌면 수치를 다시 확인해야 한다. 승인 중인 업종 매핑 검토표는 기존 파일이 있으면 덮어쓰지 않는다.

[manifest.json](manifest.json)에 입력 파일과 출력 데이터의 SHA-256, 패키지 버전, 가정, 실제 값 변경 분기를 기록했다. 출처는 서울특별시 상권분석서비스 / 소상공인시장진흥공단 상가(상권)정보다.
