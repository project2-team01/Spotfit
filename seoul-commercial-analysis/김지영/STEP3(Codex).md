# STEP 3. 파생변수 설계

작성일: 2026-10-31 · 범위: 2025년 · 상태: 설계 및 산출 완료, 자료 부족 변수는 보류

[STEP 2 전처리·결합 설계](STEP2%28Codex%29.md)에서 만든 테이블에 설명 가능한 파생변수를 추가했다. 변수의 영문명·공식·출처·목적·단위·해석·확보 가능 여부는 [전체 파생변수 정의서](step2_3/feature_dictionary.csv)에 담았다. 실제 컬럼과 결측 수는 [테이블 스키마](step2_3/table_schema.csv)에서 확인할 수 있다.

## 1. 파생변수란?

원본 숫자를 비교하기 쉬운 값으로 바꾸는 것이다. 상권 A의 분기 매출이 9억원이고 점포가 30개라면, 점포당 분기 매출은 3,000만원이고 월로 환산하면 1,000만원이다. 상권 크기가 달라도 비교하기가 조금 쉬워진다. 다만 원본 추정매출을 전체 점포 수로 나눈 값이므로 실제 가게 한 곳의 매출을 알아낸 것은 아니다.

이번에는 추천 점수를 만들지 않았다. 서로 단위가 다른 숫자를 무작정 더하는 대신, 점수화 전에 필요한 기초 지표와 자료의 빈칸을 정리했다.

## 2. 공통 계산 규칙

| 규칙 | 적용 |
| --- | --- |
| 기간 일치 | 분기 매출에는 같은 분기 점포 수. 연간 지표에는 네 분기 관측 조건 |
| 분모 | 0 또는 결측이면 결과도 결측 |
| 매출 없음 | 0원으로 채우지 않음 |
| 비율 표시 | 0.25는 25%. 매출 배율 1.25는 비교 기준의 1.25배 |
| 개폐업 지표 | 현재 재고 대비 건수비. 생존·폐업 확률이라고 부르지 않음 |
| 관광특구 | 데이터는 보존하되 주요 비교 집단에서 제외 |
| 부호·방향 | 높다고 항상 좋거나 나쁘지 않음. 업종·규모·관측 범위와 함께 해석 |
| 반복 수요 | 상권×분기 context에 보관. 업종별 합산 금지 |
| 작은 표본 | 플래그와 비교 집단 크기를 함께 표시 |
| 이상치 | 원본 지표는 유지. 최종 점수 정규화·꼬리 절단은 STEP 4에서 검토 |

## 3. 5개 분석 영역별 핵심 변수

### 3.1 상업시설 구성

| 변수 | 계산 | 의미와 활용 |
| --- | --- | --- |
| store_density_km2 | 해당 업종 점포 수÷상권 면적(km²) | 같은 면적에 얼마나 모여 있는지 비교 |
| positive_industry_count | 점포가 1개 이상인 서울 업종 수 | 영업하는 업종의 종류 |
| industry_entropy | -Σ(p×ln p), p=업종 점포÷전체 점포 | 여러 업종이 고르게 있으면 커짐 |
| normalized_industry_entropy | industry_entropy÷ln(100) | 다양성을 0~1 범위로 표시. 100개 업종에 고정한 기준 |
| store_mix_hhi | Σ(p²) | 상권 안의 업종 편중. 한 업종만 있으면 1 |
| facility_count_per_km2 | 원본 집객시설 총수÷면적 | 집객시설 밀도. 총수 정의가 불명확하므로 보조 지표 |
| semas_store_count_q4 | Q4 공간 배정 점포의 고유 ID 수 | 소상공인 업종 체계의 공간 분포. 서울 점포 수와 별도 사용 |

점포가 없는 상권은 다양성을 0점으로 억지 부여하지 않는다. 비율을 정의할 수 없으므로 엔트로피·HHI는 결측이다. 업종 수는 0개로 표현할 수 있다. 관광특구에는 이 상권 구성 파생치를 산출하지 않았다.

**쉬운 예:** 점포 10개가 모두 음식점인 상권보다 5개 업종에 2개씩 나뉜 상권의 다양성이 높다. 다양성이 높다고 모든 창업 업종에 좋은 것은 아니다.

### 3.2 매출 수준과 고객 구성

| 변수 | 계산 | 의미와 활용 |
| --- | --- | --- |
| sales_per_store_quarter | 분기 추정매출÷전체 점포 수 | 규모 차이를 줄인 점포당 분기 매출 근사값 |
| sales_per_store_month | 위 값÷3 | 월 평균으로 환산한 설명용 값 |
| sales_per_transaction | 추정매출액÷추정 매출 건수 | 결제 1건당 금액 근사값 |
| sales_vs_industry_median | 점포당 월 환산 매출÷동일 업종·동일 분기 적격 상권 중앙값 | 업종 차이를 줄인 상대 매출 수준 |
| sales_qoq_change | 당분기 매출÷직전 연속 분기 매출-1 | 단기 변화. 계절성 포함 |
| annual_sales_complete | 완전 관측 네 분기 매출 합 | 빠진 분기가 없는 연간 합계 |
| annual_monthly_sales_per_store | 연매출÷연평균 점포 수÷12 | 완전 관측 조합의 연간 월 환산값 |
| weekend_sales_share | 주말 매출÷총매출 | 주말 수요 비중 |
| weekend_daily_ratio | (주말 매출÷2)÷(주중 매출÷5) | 요일 수를 단순 보정한 주말 강도 |
| time_*_sales_share / night_sales_share | 시간대·야간 매출÷총매출 | 운영 시간에 맞는 소비 패턴 |
| sales_age_*_share | 연령별 매출÷알려진 연령별 매출 합 | 관측 고객 연령 구성 |
| female_sales_share_known | 여성 매출÷(여성+남성 매출) | 성별이 알려진 매출 안의 여성 비중 |
| age_sales_coverage / gender_sales_coverage | 알려진 연령·성별 매출 합÷총매출 | 고객 구성 자료가 총매출을 얼마나 설명하는지 표시 |

**같은 업종 안에서 비교한다.** 예를 들어 커피 업종의 월 환산 매출이 1,500만원이고 해당 분기 비교 집단의 중앙값이 1,000만원이면 지수는 1.5다. 업종 중앙값의 1.5배라는 뜻이며 상권 추천 점수 150점이라는 뜻은 아니다.

비교 집단은 관광특구 제외, 매출 관측, 점포 5개 이상이다. 같은 분기·업종에 이런 칸이 30개 이상일 때만 지수를 낸다. `industry_peer_count`로 비교 집단 크기를 함께 표시한다. 5개와 30개는 실무 운영 가정이며, 다른 기준에서도 결과가 유지되는지 STEP 4 전에 확인할 필요가 있다.

연령 구성은 알려진 연령들의 합을 분모로 사용한다. 총매출에는 성별·연령이 알려지지 않은 매출이 있을 수 있으므로 구성비와 자료 보유 비율을 함께 본다. 시간대 구간 길이는 서로 다르며, 주말 하루 비율도 실제 영업일·공휴일 수를 보정한 값은 아니다.

### 3.3 경쟁 구조

| 변수 | 계산 | 의미와 활용 |
| --- | --- | --- |
| store_count | K02 전체 점포 수(원본) | 같은 상권·업종에 점포가 몇 개인지 |
| franchise_share | 프랜차이즈 점포÷전체 점포 | 가맹점과 독립점포의 구성 |
| store_density_km2 | 해당 업종 점포÷면적 | 공간상 밀집 정도 |
| industry_spatial_hhi | Σ상권(해당 업종 점포÷서울 해당 업종 점포)² | 업종이 특정 상권에 모이는 정도 |
| stores_per_1000_floating_population | 상권 전체 점포÷원본 유동인구×1,000 | 수요 대비 공급의 참고 지표 |

`store_mix_hhi`와 `industry_spatial_hhi`는 합산 방향이 다르다. 전자는 상권 안에서 업종들이 어떻게 나뉘는지, 후자는 한 업종이 서울의 상권들에 어떻게 퍼지는지 본다. 후자는 같은 업종·분기에서는 모든 상권에 같은 값이 붙으며 개별 상권의 경쟁 위험을 단독으로 구분하지 못한다.

점포 수가 많은 곳은 수요도 많을 수 있다. 점포 수만으로 자동 감점하지 않는다. 유동인구 대비 점포 수도 고유 방문자나 구매자 수로 나눈 값이 아니며, 상권별 원자료 인구 단위·측정 방식을 확인하기 전에는 보조 비교로 제한한다.

### 3.4 변화와 안정성

| 변수 | 계산 | 의미와 활용 |
| --- | --- | --- |
| open_count_ratio | 분기 개업 건수÷당분기 점포 수 | 해당 규모 대비 개업 움직임 |
| close_count_ratio | 분기 폐업 건수÷당분기 점포 수 | 해당 규모 대비 폐업 움직임 |
| net_open_count | 개업 건수-폐업 건수 | 개폐업 차이. 재고 변화와 별개 |
| store_qoq_change | 당분기 점포÷직전 분기 점포-1 | 연속 분기의 실제 점포 재고 변화 |
| annual_open_count_ratio | 연간 개업 건수÷네 분기 평균점포 수 | 연간 개업 빈도 근사값 |
| annual_close_count_ratio | 연간 폐업 건수÷네 분기 평균점포 수 | 연간 폐업 빈도 근사값 |
| annual_sales_cv | 네 분기 매출 표준편차÷평균 | 2025년 안의 매출 출렁임 |

점포 2개인 칸에서 폐업 1건이면 단순 비율은 50%다. 점포 200개인 칸에서 1건이면 0.5%다. 작은 칸의 비율은 몇 건만으로도 크게 달라진다. 그래서 `small_store_flag`와 원본 건수를 함께 제공한다.

점포가 0이지만 폐업이 기록된 칸은 `zero_stock_with_closure=True`로 표시한다. 이때 폐업 건수를 없애거나 계산 불가 비율을 0%로 바꾸지 않는다. 연간 집계에서도 그 폐업 건수는 보존한다.

연간 비율은 점포 자료가 네 분기 모두 있을 때만 산출한다. 매출 변동계수는 점포와 매출이 네 분기 모두 관측될 때만 산출한다. 4개의 값으로 장기 안정성을 확정할 수 없으며, 업종 계절성이 큰 경우 값이 커질 수 있다.

### 3.5 입지와 수요 적합성

| 변수 | 계산 | 의미와 활용 |
| --- | --- | --- |
| floating_population_per_km2 | 원본 유동인구÷면적 | 공간 크기를 보정한 유동인구 지표 |
| worker_population_per_km2 | 원본 직장인구÷면적 | 업무 수요의 밀도 |
| resident_population_per_km2 | 원본 상주인구÷면적 | 주거 수요의 밀도 |
| facility_count_per_km2 | 원본 집객시설 총수÷면적 | 시설 밀집도 |
| floating_age_*_share | 연령별 유동인구÷총유동인구 | 지나가는 인구의 연령 구성 |
| floating_peak_time_share | 가장 큰 시간대 인구÷총유동인구 | 특정 시간 구간의 인구 집중 |

유동인구의 연령 비중과 매출의 연령 비중은 별개의 정보다. ‘20대가 많이 지나감’과 ‘20대 소비 비중이 높음’은 같지 않다. 먼저 두 지표를 나란히 비교하는 용도로 쓴다. 서로 다른 조사 범위·단위이므로 비율을 나눠 실제 구매전환율로 부르지 않는다.

직장인구÷(직장+상주+유동인구)와 같은 합성 비율은 만들지 않았다. 측정 개념과 실제 작성시점이 달라 같은 모집단의 구성비라고 볼 수 없기 때문이다.

## 4. 품질 플래그와 분석 대상

| 컬럼 | 뜻 |

이 플래그는 사용자 금융 성향 점수와 다르다. 자료가 없는 상권에 낮은 점수를 주는 대신 ‘이 항목은 자료 부족’이라고 설명하는 데 사용한다.

## 5. 확보하지 못해 계산하지 않은 변수

| 변수 | 필요한 추가 자료 | 현재 처리 |
| --- | --- | --- |
| sales_yoy_change | 2024년 같은 분기 추정매출·점포·공간 비교 기준 | 보류. 전분기 증감으로 대체하지 않음 |
| population_growth | 일관된 과거 인구와 실제 작성 시점 | 보류. 반복 값을 실제 성장 0%로 표시하지 않음 |
| business_survival_probability | 점포별 개폐업 시점과 장기 추적 이력 | 보류. 폐업 건수비를 확률로 바꾸지 않음 |
| budget_fit | 임대료·보증금·권리금·시설비·업종별 비용 | 보류. 매출만으로 예산 가능 여부를 판단하지 않음 |
| mapped_semas_competitor_count | 승인된 소상공인↔서울 업종 매핑 | 보류. 별도 소상공인 업종 집계만 제공 |

사전에는 보류 항목을 포함하지만 데이터 테이블에 숫자 0으로 된 가짜 컬럼을 만들지 않는다.

## 6. STEP 4에 넘길 기준

1. 희망 업종을 먼저 정하고, 관광특구를 뺀 같은 업종의 상권들을 비교한다.
2. 자료가 부족한 지표는 감점하지 않고 산출 불가와 이유를 표시한다.
3. 매출 수준·개폐업·수요를 한 가지 숫자로 섣불리 통합하지 않는다. 업종·상권 규모에 따라 해석이 다르다.
4. 상대 매출 지수의 점포 5개·비교집단 30개 기준을 바꿔 순위 민감도를 확인한다.

6. 2025년 네 분기를 무작위 행으로 나눠 같은 상권의 정보를 학습·평가에 섞지 않는다. 이후 예측 검증은 시간·상권 분리와 당시 이용 가능한 자료를 확인한다.
7. 가중치·정규화·최종 점수·MBTI별 추천은 STEP 4·5에서 별도로 설계한다.
