# STEP 5 · 상권 8유형 분석과 선호 유형 탐색

2026-11-12에 사용자 제시 L/V·E/P·S/D 8유형을 2025년 팀 공통 데이터로 검토했습니다. **분석용 대리분류 후보이며 실제 고객·금융 성향이나 창업 성과가 검증된 유형은 아닙니다.**

## 먼저 열 파일

1. [STEP5 분석 보고서](report/STEP5_분석보고서.md): 결과·보류·민감도·검증·남은 문제.
2. [STEP5 결과 요약 HTML](report/STEP5_결과요약.html): 내려받아 브라우저로 열면 표와 그래프를 볼 수 있습니다. Plotly를 포함해 외부 설치·인터넷 없이 열 수 있는 요약 보고서입니다.
3. [유형 후보 미리보기](data/유형후보_미리보기.csv): 유형별 예시와 보류 행을 작은 표로 확인합니다.
4. [8유형 정의와 결과](data/8유형_정의와_결과.csv): 원래 코드·이름과 정리한 코드·이름을 함께 보존합니다.

G가 남아 있던 LEG/LPG/VEG/VPG는 LED/LPD/VED/VPD로 통일했습니다. 성장이라는 뜻을 피하기 위해 바꾼 유형 이름은 **분석용 제안**입니다. D는 2025년 내 관측 변동성으로 사용하며, 소비·방문 증가나 장기 성장으로 읽지 않습니다. 상세 가정은 [DESIGN](DESIGN.md)에 있습니다.

## 결과 요약

- 전체 상권×업종 76,591개 조합과 모든 보류 행을 보존했습니다.
- STEP 4 점수 대상 20,522개 중 9,267개에 세 축이 있는 후보 코드가 생겼고 11,255개는 보류했습니다.
- 53개 업종에서 세 축을 가진 후보가 있습니다. 매출 미제공 38개 업종은 E/P·S/D·완전 유형을 강제로 채우지 않았습니다.
- 17개 검사를 통과했습니다. 원본 손계산·결측과 소표본 보존·두 번 실행 바이트 동일·다섯 가지 변조 탐지를 포함합니다.

## 이번 STEP 5의 범위

원래 STEP 5는 사용자의 금융 MBTI·위험 감수 성향·예산을 통한 개인화 설계입니다. 이번 8유형은 **상권의 성격**이므로 사용자 금융 성향과 구분했습니다. 실제 사용자 응답은 없으며 예산 적합성을 평가할 임대료·보증금·권리금·시설비도 없습니다.

실험에서는 사용자가 선호 유형과 희망 업종을 선택했다고 가정합니다. 유형 필터로 후보를 좁힌 뒤, L은 주민 중심·V는 유동 중심 수요 점수를 연결합니다. 이 연결과 경계값은 가정입니다. 나머지 STEP 4 기본 가중치는 유지하고 근거 없는 8유형별 차등 가중치를 만들지 않았습니다. 정확한 일치 후보가 없으면 결과 없음으로 표시합니다. 부분 일치는 명시적으로 허용한 경우에만 별도 표시합니다.

이 분석의 최종 판정 단위는 **상권×업종**입니다. 같은 상권도 업종에 따라 E/P·S/D가 달라질 수 있습니다. L/V만 상권 수준으로 따로 공유합니다. 유형별 상권 고유 수를 더하면 중복될 수 있습니다.

## 재현 방법

팀 저장소 전체를 받은 뒤 저장소 루트에서 실행합니다. [uv](https://docs.astral.sh/uv/)가 필요합니다. 원본 `data/raw/`는 필요 없습니다. 다른 팀원의 입력과 기존 STEP 4는 읽기만 하고 이 폴더 안에 결과를 만듭니다.

```powershell
uv run --project "박성은/step5_personalization" python "박성은/step5_personalization/analyze_step5.py"
uv run --project "박성은/step5_personalization" python "박성은/step5_personalization/test_step5.py"
uv run --project "박성은/step5_personalization" python "박성은/step5_personalization/write_report.py"
```

선호 유형·희망 업종 탐색 예시:

```powershell
uv run --project "박성은/step5_personalization" python "박성은/step5_personalization/explore.py" --industry CS100010 --type LES
uv run --project "박성은/step5_personalization" python "박성은/step5_personalization/explore.py" --industry CS100010 --type LEG
```

두 번째 명령의 LEG는 LED로 변환됩니다. 부분 일치가 필요하면 `--allow-partial`을 명시합니다. 결과는 이 폴더 `data/탐색_…csv`에만 저장합니다. 매출 미제공 업종을 정확 일치로 검색하면 결과가 없을 수 있으며 임의로 보충하지 않습니다.
