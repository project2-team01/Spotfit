**공유 주소: https://spotfit-park-2025.park24401859.chatgpt.site/#overview**

## 통합 기준

- 2025년 1~4분기, 관광특구 제외, 평균 점포 5개 이상, 업종 비교 상권 30곳 이상
- 매출·경쟁·안정성 점수는 기존 성은·승희 구현을 보존하고, 기본 수요 평균은 지영의 세 인구 완비 조건으로 통일
- L/V는 상주/(상주+직장)의 45~55%를 보류하고, E/P는 같은 업종 건당 금액 백분위 45~55를 보류
- S/D는 공식 2025Q4 영업 기간 지표 HH→S, LL→D. LH/HL은 공식 명칭을 그대로 보존하고 S/D 대응만 보류
- 기본 가중치 30·25·15·30, 영역 결측은 0점 대신 비중 재배분. 가중치·수요 변경은 실험으로 표시
- 과거 분기 변동성은 별도 참고. L→주민/V→유동 수요 연결은 기본 끄기인 선택 기능
- 검사 각 축 5문항 중 4:1 이상만 필터 제안. 3:2·미완료 축은 제한하지 않고 사용자 직접 선택을 우선

S/D의 의미를 성장·수익·저위험으로 설명하지 않습니다. L/V와 E/P는 대리분류이며 검사도 팀 제작 운영 선호 초안입니다. 예산 적합성이나 성공률은 판단하지 않습니다.

## 원본 보존과 기여

- 김지영: 공통 패널·인구·업종 데이터, EDA·결측 및 S/G 대안 설계
- 이승희: 점수 구현, 공식 상권변화지표·S/D 연결, 15문항 검사지 구조와 비교 시각화
- 박성은: 입력 재계산 검증, 분기 변동성·민감도, 경계 정밀도 보정, 공통 웹 상태·공유·통합 검증

다른 팀원 폴더와 기존 박성은 STEP 4·5 분석은 변경하지 않았습니다. 입력 버전은 `22d1c6842c67ab4902e0317f8afdf32c85c98870`이며 파일별 SHA-256은 `data/integration_meta.json`에 있습니다. 텍스트 지문은 LF로 정규화하여 Windows 체크아웃의 줄바꿈 차이를 구별합니다.

기존 공식 S/D 구현의 7,680개 중 2개는 백분위 55의 부동소수점 오차를 바로잡아 보류로 이동했습니다. 변경한 이름·업종·원래 백분위와 새 판정은 CSV에 남겼습니다. 소수 12자리 정리 외에는 E/P 임계값을 넓히지 않았습니다.

## 재현과 실행

팀 저장소 전체가 필요합니다. 원본 `data/raw/`나 외부 API 키는 필요 없습니다. 저장소 루트에서 기존 uv 환경을 사용합니다.

```powershell
uv run --frozen --project "박성은/step5_personalization" python "박성은/integrated_dashboard/build.py"
uv run --frozen --project "박성은/step5_personalization" python "박성은/integrated_dashboard/test_integrated.py"
node "박성은/integrated_dashboard/verify.js"
uv run --frozen --project "박성은/step5_personalization" python -m http.server 27186 --directory "박성은/integrated_dashboard/dist"
```

미리보기는 http://127.0.0.1:27186/#overview 입니다. 웹 묶음 ZIP을 사용하는 경우 압축을 풀고 그 폴더에서 `python -m http.server 27186`을 실행해도 됩니다. `index.html` 더블클릭 대신 HTTP 서버를 사용하세요.

`dist/data/`, `dist/assets/` 및 Python 대조 fixture는 빌드로 생성하며 Git에 중복해서 올리지 않습니다. ZIP에는 실행용 생성 파일이 모두 들어 있습니다. 독립 환경에서는 `requirements.txt`의 패키지를 사용하면 됩니다.
