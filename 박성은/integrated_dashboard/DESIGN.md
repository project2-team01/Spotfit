# 통합 기준과 선택 이유

## 목적과 판정 단위

희망 업종 안에서 상권을 비교하고, 사용자가 원하는 운영 환경에 맞는 후보를 좁힙니다. 최종 단위는 상권×업종입니다. L/V와 S/D는 상권 수준 속성을 연결하고 E/P는 업종마다 따로 계산합니다. 모든 화면은 `core.js`의 한 점수·필터 함수를 사용합니다.

## 세 팀원 분석에서 통합한 선택

| 항목 | 채택한 기준 | 이유와 대안 처리 |
|---|---|---|
| 공통 입력 | 김지영 STEP 2·3 패널 및 EDA 산출물 | 점수 대상이 세 구현에서 같고 원패널부터 점포·폐업·건당 금액을 재계산해 확인 가능 |
| 점수 4영역 | 기존 박성은·이승희 영역 점수 | 지영의 같은 지표 점수와도 일치. 순위 산정 단위를 새로 섞지 않음 |
| 기본 수요 | 김지영의 세 인구 완비 평균 | 서로 다른 구성의 평균을 같은 지표로 보지 않도록 통일. 기존 일부 평균은 대안 모드로 보존 |
| L/V | 성은·승희 상주/(상주+직장) 45/55 | 경계 보류가 있고 동일 구현 활용 가능. 유동/상주를 포함하는 지영 안은 향후 대안 비교 사항. 방문객 구성을 검증한 값은 아님 |
| E/P | 성은·승희 같은 업종 건당 금액 45/55 | 원하는 업종의 상대 수준을 직접 반영. 상권 전체의 거래 건수 가중 평균과 구별 |
| S/D | 승희의 공식 2025Q4 영업 기간 지표 | 관측 변동성과 다른 개념으로 정의. HH·LL만 대응시키고 LH·HL은 원래 명칭을 보존 |
| 분기 변동성 | 성은의 매출·유동 CV | 상세의 보조 분석으로 남기고 점수·현재 S/D에 다시 더하지 않음 |
| 유형별 비중 | 기본 30·25·15·30 유지 | 지영 S/G 비중은 민감도 대안에 포함. 근거 없는 개인 성향별 비중을 기본값으로 추가하지 않음 |
| 검사 | 승희 구조·지영의 원문·채점 검증 접근 | 1~10번 보존. 11~15번은 영업 기간에 맞게 정비. 수익·폐업 빈도·방문 증가를 D의 속성으로 약속하지 않음 |
| 화면 | 박성은 공유 웹과 비교 시각화 | 검사·지역·유형·가중치·수요 상태를 모든 화면에 공통 적용하고 CSV에 설정을 기록 |

## 계산 규칙

평균 점포 5개, 같은 업종 비교 30곳 이상에서 점수를 냅니다. 각 영역은 같은 업종 안의 평균 동점 순위 백분위입니다. 매출은 높을수록, 경쟁 지표와 축소 추정 폐업률은 낮을수록 높은 점수입니다. 종합 점수는 유효한 영역의 점수×가중치 합을 유효 가중치 합으로 나눕니다. 가중치가 모두 0이면 점수와 순위를 계산하지 않습니다.

기본 수요 평균은 유동·직장·상주 밀도의 백분위가 모두 있어야 합니다. 사용자가 단일 수요나 일부 평균을 선택하면 변경한 실험으로 표시합니다. 지역과 선호로 좁혀도 업종 내 점수를 다시 정규화하지 않습니다.

E/P는 네 분기 관측, 양의 유효 건당 금액, 비교 30곳, 반복 매출 제외를 요구합니다. 백분위를 소수 12자리로 정리하여 45와 55의 경계를 포함해 보류합니다. 이로 인해 기존 저장 산출물의 대청초등학교·제과점, 천호역·PC방 두 조합이 P에서 보류로 바뀌었습니다.

## 사용자 선호와 보류

선호 축을 선택하고 필터를 적용한 경우 해당 축의 상권 판정이 같은 곳만 남깁니다. 선택하지 않은 축은 제한하지 않습니다. 모든 축을 판정할 수 있어야 8유형 코드를 붙입니다. 일부 축이 보류인 조합도 제한하지 않은 축이면 후보가 될 수 있으며 상태를 명시합니다. 결과가 없다고 다른 유형으로 대체하지 않습니다.

15문항은 각 축의 5문항을 모두 답한 뒤 4:1 이상만 뚜렷한 필터로 제안합니다. 3:2 또는 미완료 축은 제한하지 않습니다. 세 글자 다수 결과와 실제 적용하는 필터가 다를 수 있음을 화면에 표시합니다. 응답 지우기는 검사에서 적용한 선호 조건도 해제하고, 수동으로 설정한 조건은 보존합니다. 서버 저장·전송·사용자 추론은 없습니다.

L→상주/V→유동 수요 연결은 명시적으로 켜고 L/V 선호 필터가 적용될 때만 사용합니다. 그 경우 수요 선택을 잠그고 실제 모드를 보여 줍니다. 어떤 후보마다 다른 모드로 점수를 계산하지 않습니다.

## 해석과 출처 보존

공식 지표의 H/L 코드는 서울 평균 영업 기간과의 비교입니다. 공유 마트에 서울 평균의 두 원값은 없어 임의로 채우지 않습니다. 제공된 공식 코드와 명칭을 사용하고 각 상권의 운영·폐업 평균 개월을 표시합니다.

HH→S, LL→D 연결과 유형 이름은 팀 전체 승인으로 주장하지 않는 통합 구현 선택입니다. S는 저위험, D는 높은 수익이나 성장이라는 뜻이 아닙니다. 비용·이익·실제 사용자 성과가 없어 예산 적합성과 성공률을 판단하지 않습니다. 원입력, 기존 분석, 기여자, 임계값 가정과 버전을 모두 보존합니다.
