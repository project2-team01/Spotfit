# 팀 분석 재검토와 통합 선택

2026-11-23 · 비교 입력: 팀 저장소 main `aafbb4a` (11월 21일 최종 산출물 포함)

이번 검토는 기존 박성은 통합안을 정답으로 놓지 않았다. 공통 원패널에서 점수를 다시 계산하고 김지영·이승희·박성은의 저장 결과와 대조했다. 원자료와 팀원 폴더는 읽기만 했으며 통합 구현은 별도 폴더에 작성했다.

## 판단 기준과 확인 범위

1. 목적: 희망 업종의 입지를 비교하는가. 분석 단위와 후보 단위가 같은가.
2. 재현: 원패널에서 수치·키·분모·정렬을 재계산할 수 있는가.
3. 해석: 측정한 변수의 뜻을 성공률·성장·실제 고객 구성으로 바꾸지 않는가.
4. 불확실성: 소표본·결측·경계·자료 시점과 가정을 드러내는가.
5. 산출물 완결성: 데이터·변수사전·보고서·시각화·도구가 연결되는가.

읽은 자료: 김지영 STEP 2·3, STEP 4·5 코드와 산출물, STEP 6 최종 HTML 및 생성 코드; 이승희 STEP 4·5 코드와 산출물, 공식 지표 마트, 최신 검사지, pixel_theme; 박성은 기존 STEP 4·5 및 통합 v1; 공통 분석계획서; 11월 19일 합의와 11월 21일 Slack 비교 글. Slack Canvas는 무료 워크스페이스 API 제한으로 읽지 못했다. 복제된 외부 Claude 게시본은 계산 소스 대신 사용하지 않았다. 실제 화면 검증은 이 자료로 생성한 통합본에서 수행했다.

| 검사 | 최신 이승희 15문항, 각 축 4:1 이상만 적용 | 3:2 및 미완료를 강제 확정하지 않음. 이미 뚜렷한 일부 축은 활용 가능. 금융·심리검사 타당도는 검증 안 됨 |
| STEP 6 시각화 7 | 공통 점수로 세 축 후보·상위 5곳 재계산 | 예전 S/G 차등 가중치 결과를 단순히 D로 이름만 바꾸지 않음 |

45/55, 점포 5개, 업종 비교 30곳, 지도 10곳은 모두 운영 가정이다. 이 수치가 통계적 정답이거나 실제 성과를 최대로 만든다는 결론은 낼 수 없다. 그렇다고 임의의 새 경계로 바꾸는 것도 검증된 개선이 아니다. 이번 통합은 비교와 해석을 일관되게 만드는 기준이다.

## 직접 대조한 결과

- 김지영 저장 점수 77,173행을 공통 원패널에서 재생성: 매출·경쟁·안정성·수요·종합 점수 차이 0행.
- 점수 대상 20,522조합에서 김지영·최신 이승희·이번 통합의 기본 점수 차이 0개.
- 예전 박성은 STEP 4와는 126개 기본 점수가 다름. 최대 절대 차이 23.081점. 원인은 일부 인구만 평균하던 수요 처리.
- 최신 이승희와 세 축 최종 유형 차이 0개. 예전 경계 계산 오차 2개는 최신 승희 코드에도 이미 수정됨.
- 김지영의 상권 단위 방식과 이번 분류가 모두 판정한 조합 중 L/V는 19,024개 중 4,113개, E/P는 12,271개 중 4,749개가 다름. 이는 서로 다른 정의·분모를 사용한 영향이며 그 자체로 어느 분석이 오류라는 증거가 아님.
- 분석 행 77,173개에는 평균 점포 0인 582개 조합이 포함됨. 양수 점포 조합은 76,591개. 점수 대상은 두 방식 모두 20,522개로 같음.
- 세 축 확정 7,678조합, 일부 축 보류 12,844조합. 고유 상권 수가 아님.
- 공식 LH/HL 연결 보류는 599/1,644상권(약 36.4%). 전체 유형 보류 12,844조합에는 L/V·E/P 자료 부족·경계도 섞이므로 둘을 같은 분모로 설명하지 않음.

수치와 입력 SHA-256은 `data/audit.json`, 정의가 달라진 행은 `data/LV_정의차이.csv`, `data/EP_정의차이.csv`에 저장한다. Node 검증은 독립 Python의 20,522개 점수, 77업종×8유형의 상위 5곳, 32,768개 설문 완성 응답을 대조한다.

## 공유·재현

- HTML 하나: `report/SpotFit_팀통합_최종대시보드.html`을 더블클릭해 열 수 있다. 분석 차트·지도·검사·가중치 계산에 외부 요청이 없다. 보고서·원출처 링크는 인터넷이 필요하다.
- 공개 공유 주소: https://spotfit-park-2025.park24401859.chatgpt.site/#s1
- 6장 구 선택은 그 화면의 탐색 범위다. 서울 순위와 7·8장의 서울 전체 업종 비교는 바꾸지 않으며 화면에 이 범위를 표시한다.
- 7장의 선호는 후보를 거르는 조건이다. 검사 결과 때문에 가중치가 자동 변경되지 않는다. 가중치는 6·7·8장 모두 공통이다.

실제 고객·개별 점포 비용·순이익·창업 후 성과가 없으므로 추천 정확도, 성공률, 예산 적합성은 검증하지 못했다.
