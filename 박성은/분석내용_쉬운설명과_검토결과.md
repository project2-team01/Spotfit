# 이번 분석의 내용과 재검토 결과

검토일: 2026-11-04. 대상: 2025년 서울 상권 STEP 2·3 1차 분석본. 검토 기준은 팀 저장소에 반영된 [39e204f 커밋](https://github.com/project2-team01/Spotfit/commit/39e204fc0e41c100912d2e3685ea4acb486575ec)의 분석 코드·정의표와 로컬에 보존한 원본 및 가공 데이터입니다.

**현재 결과는 상권을 비교하기 위한 데이터 전처리·결합과 지표 생성의 1차 결과로 사용할 수 있습니다.** 재검토에서 원본 보존, 데이터 결합, 32개 지표의 수식과 저장값 일치를 확인했습니다. 업종을 연결하는 방식과 중첩 상권의 점포 배정에는 분석자의 선택이 들어가므로, 이 부분은 비교 목적에 맞게 검토해야 합니다. 창업 성공·수익 예측, 금융 MBTI별 추천 성능까지 검증한 단계는 아닙니다.

이 문서는 기존 작성자가 수행한 자체 재검토입니다. 별도 전문가의 검증이나 공공기관의 인증을 의미하지 않습니다.

## 1. 무엇을 알아보기 위한 작업인가

서울의 상권마다 매출·점포·인구·시설 자료가 따로 있어, 같은 지역과 업종을 기준으로 비교하기 어려웠습니다. 이번에는 이 자료를 연결하고 다음 질문에 사용할 숫자를 만들었습니다.

- 같은 업종을 놓고 볼 때 상권별 추정매출과 점포 수가 얼마나 다른가?
- 해당 업종의 점포가 얼마나 밀집해 있고 프랜차이즈 비중은 어느 정도인가?
- 유동인구, 직장인구, 상주인구를 통해 어떤 수요 특성을 비교할 수 있는가?
- 주말·점심·저녁의 매출 비중과 분기 사이 변화는 어떤가?
- 한 상권에 어떤 업종들이 섞여 있는가?

이번 단계의 산출물은 **이 질문들을 탐색할 수 있는 표와 계산 변수**입니다. 인구·시설로 기대매출을 예측한 모형, 예측치와 실제값의 차이인 소비 갭, 가설검정, 최종 추천순위는 아직 만들지 않았습니다. 따라서 현재 결과만으로 “저평가 상권을 입증했다”거나 “이곳에 창업하면 성공한다”고 말할 수는 없습니다.

## 2. 어떤 자료를 어떻게 연결했나

| 자료 | 담고 있는 내용 | 이번에 사용한 방법 |
| --- | --- | --- |
| S01 소진공 상가정보 | 개별 점포의 업종과 위치 | 2025-12-31 점포 목록을 좌표로 상권에 연결 |
| S02 업종코드표 | 소진공 업종코드의 이름 | S01의 247개 소분류 확인 |
| K01 서울 추정매출 | 상권·업종별 매출과 시간·고객 구성 | 2025년 분기별 매출 비교 |
| K02 서울 점포 | 점포·프랜차이즈·개업·폐업 수 | 매출과 같은 분기·상권·업종으로 연결 |
| K03 상권 영역 | 1,650개 상권의 경계 | 점포의 공간 연결과 면적당 밀도 계산 |
| K04 길단위인구 | 유동인구와 연령·시간대별 구성 | 수요 특성 비교 |
| K05~K07 | 집객시설·직장인구·상주인구 | 2025년 자료만 골라 상권에 연결 |

**STEP 2**에서는 읽는 인코딩, 컬럼명, 분기와 코드를 맞추고 서로 연결했습니다. **STEP 3**에서는 연결된 값으로 점포당 추정매출, 경쟁 밀도, 프랜차이즈 비중 등의 변수를 계산했습니다. 인수인계 문서의 전제에 따라 K01의 `당월_매출_금액`은 분기 추정매출로 사용했습니다.

주 분석표의 한 행은 **분기 하나 × 상권 하나 × 서울 서비스업종 하나**입니다. 예를 들어 “2025년 4분기, 성수1가1동주민센터 상권, 커피-음료 업종”이 한 행입니다. 여기서 주민센터는 상권의 이름이며 해당 행정동 전체를 뜻하지 않습니다.

- 상권·업종·분기 표: **304,775행**. 점포 수나 설문 응답자 수가 아닙니다.
- 상권·분기별 인구·시설 표: **6,600행**. 1,650개 상권과 4개 분기의 조합입니다.
- 소진공 점포: **534,978개**. 서울 서비스업종과 다른 분류 체계이므로 별도 구성표도 유지했습니다.

주 분석표는 원자료에 존재하는 상권·업종 조합을 보존했습니다. 1,650개 상권 × 100개 업종 × 4개 분기의 가능한 660,000개 조합을 모두 채운 표는 아닙니다. 표에 없는 조합을 임의로 0으로 만들면 안 됩니다.

## 3. 제대로 계산됐는지 무엇을 확인했나

기존 실행 기록에는 기본 검사 193개와 저장 결과 검증 52개가 있습니다. 이번에는 설명서의 근거를 확인하기 위해 원본 수치와 저장된 점포 배정 결과를 읽어 **11개 구조·보존 검사와 32개 지표별 재계산 검사**를 추가로 수행했습니다. 모두 통과했습니다.

| 재검토 항목 | 확인한 결과 | 이 검사로 판단할 수 있는 범위 |
| --- | --- | --- |
| 원본 파일 | 18개 파일의 SHA-256이 인수인계 기록과 일치 | 검토한 원본이 수집 당시 파일과 같음 |
| 키와 행 | 주 분석표의 키 중복 없음, 상권·분기 표 6,600행 확인 | 결합 과정에서 행이 중복 증식하지 않음 |
| 원본 매출·점포 수 | 매출 85,732행과 점포 304,775행의 수치가 저장 결과와 일치 | 결합하면서 원 수치를 잃거나 바꾸지 않음 |
| 매출 결측 | 매출 행이 없는 경우를 결측으로 유지 | 미관측을 매출 0으로 오해하지 않도록 처리 |
| 시간 정렬 | 12월 말 소진공 점포 수를 Q1~Q3에 복사하지 않음 | 과거 분기에 미래의 점포 구성을 끼워 넣지 않음 |
| 32개 지표 | 원본 수치 또는 저장된 점포 배정 결과로 다시 계산한 값과 일치 | 정의한 공식을 코드가 일관되게 계산함 |

재계산은 저장된 유효 행 전부를 대상으로 했으며, 부동소수점 계산에는 작은 수치 허용오차를 적용했습니다. 공간 연결 자체는 기존 후보·배정 기록을 검토했고, 이번에 모든 점포를 외부 지도나 현장에서 다시 확인한 것은 아닙니다.

검사 통과는 공공 원자료의 추정 정확도, 업종 대응의 현실 적합성, 추천의 성과까지 보장하지 않습니다. 예를 들어 공식이 올바르게 계산돼도 분모의 의미를 잘못 설명하면 해석이 달라집니다.

## 4. 실제 결과 한 행을 읽어보면

추천순위를 만들기 위한 선택이 아니라 계산을 설명하기 위해, 2025Q4의 커피-음료 업종 중 점포가 5개 이상이고 매출이 관측된 성수 지역의 골목상권을 상권코드 순으로 골랐습니다.

대상: **성수1가1동주민센터 상권(`3110127`) · 커피-음료(`CS100010`) · 2025Q4**.

| 항목 | 원 수치 또는 계산 | 읽는 방법 |
| --- | ---: | --- |
| 분기 추정매출 | 184,219,542원 | 이 상권·업종의 분기 단위 추정치 |
| 전체 점포 수 | 11개 | K02가 제공한 해당 업종의 점포 수 |
| 점포당 분기 추정매출 | 184,219,542 ÷ 11 = 약 16,747,231원 | 두 집계량을 나눈 비교용 대리지표. 개별 카페의 실제 매출이나 이익은 아님 |
| 프랜차이즈 비중 | 3 ÷ 11 = 약 27.3% | 해당 업종 점포 중 프랜차이즈가 차지하는 비중 |
| 동일 업종 점포 밀도 | 약 283.7개/km² | 상권 면적을 기준으로 한 공간적 밀집도 |
| 주말 매출 비중 | 약 18.0% | 주중·주말 매출 합 중 주말 매출의 몫. 하루 평균 비교는 아님 |
| 직전 분기 대비 매출 변화 | 약 -28.0% | Q3에서 Q4로 관측 추정매출이 변한 정도. 장기 쇠퇴나 미래 매출 하락을 입증하지 않음 |

이 한 행으로 설명할 수 있는 것은 해당 기간에 기록된 지역·업종의 특징입니다. 임대료, 인건비, 원가, 신규 점포의 매출, 창업자의 운영 능력은 포함하지 않았으므로 수익성이나 입점 적합성을 확정할 수 없습니다.

## 5. 사용할 때 특히 주의해야 할 부분

### 5.1 매출이 관측된 행은 주 분석표의 28.1%다

| 구분 | 행 수 |
| --- | ---: |
| 주 분석표 전체 | 304,775 |
| 매출 관측 | 85,732 |
| 매출 미관측 | 219,043 |
| 미관측 중 매출 원자료에 업종 자체가 없는 경우 | 58,517 |
| 미관측 중 제공 업종이지만 해당 상권·분기·업종의 매출 행이 없는 경우 | 160,526 |

K02에는 100개 업종이 있지만 K01의 매출은 62개 업종만 제공합니다. 제공 업종 안에서도 모든 상권·분기 조합에 매출 행이 있는 것은 아닙니다. **매출 미관측은 매출 0이나 낮은 사업성이라는 뜻이 아닙니다.** 현재 자료만으로 미관측 원인을 전부 확정할 수 없고, 임의로 채우면 비교 결과가 왜곡될 수 있습니다.

매출이 관측된 행만 고르면 분석 대상의 성격이 달라질 수 있습니다. 결과를 보고할 때에는 선택한 업종·분기의 관측 행 수와 제외 범위를 함께 표시해야 합니다. 매출 관측 행 중 점포 수가 5개 미만인 경우도 25,685행으로 약 30.0%입니다. 작은 분모에 민감한 지표를 특히 살펴야 합니다. 기존의 ‘5개 미만’ 표시는 검토를 돕는 기준이며 통계적으로 검증된 안전 기준은 아닙니다.

### 5.2 점포의 대표 배정 수와 상권 내부의 원자료 점포 수는 구분해야 한다

한 점포가 관광특구와 작은 상권에 함께 포함될 수 있습니다. 기존 코드의 대표 배정은 이 가운데 면적이 가장 작은 상권을 하나 고릅니다. 같은 점포를 여러 번 세지 않는 집계에는 쓸 수 있지만, 넓은 상권의 내부 점포를 전부 보여주는 방식은 아닙니다.

실제로 **종로·청계 관광특구(`3001494`)는 대표 배정 수가 0개이고, 중첩을 허용해 경계 안의 점포를 세면 3,286개**입니다. 이를 “관광특구에 점포가 없다”로 읽으면 잘못된 설명입니다.

이 수치는 소진공 원자료에 기록된 점포의 좌표 기준 집계이며, 현재 현장 점포의 전수조사 결과는 아닙니다.

| 알고 싶은 것 | 사용할 결과 |
| --- | --- |
| 점포마다 대표 상권 하나를 정해 중복을 줄인 집계 | `snapshot_store_count`, 대표 배정 소분류 표 |
| 이 상권 경계 안에 어떤 점포가 들어 있는지 | `snapshot_all_membership_store_count`, 모든 소속 소분류 표 |
| 대표 배정 선택의 영향을 덜 받는 점포 수 | 유일매칭 점포 수를 함께 비교 |

상권 내부 시설 구성을 설명할 때에는 모든 소속 집계를 우선 확인하는 것이 적합합니다. 다만 이 집계를 여러 상권 사이에서 더하면 동일 점포가 중복될 수 있습니다. 현재 업종 HHI와 엔트로피는 대표 배정 기준이므로, 넓은 상권의 구성 비교에 사용할 때는 모든 소속 기준으로 다시 산출할지 결정해야 합니다.

### 5.3 소진공 업종과 서울 업종의 연결은 잠정 가정이다

소진공 247개 소분류 중 131개를 서울 89개 업종에 연결했고, 116개 소분류는 미연계로 남겼습니다. 연결한 항목도 공식 동등 분류로 검증된 것은 아닙니다. 전체 소진공 점포 중 약 73.1%가 잠정 업종 대응에 해당하지만, 이 수치는 대응의 정확도를 뜻하지 않습니다.

따라서 서울 K02 점포 수를 소진공 대응 점포 수로 바꾸거나, 두 숫자의 차이를 곧바로 부족 업종의 근거로 사용하면 안 됩니다. 매출·점포당매출·서울 업종 경쟁 지표는 우선 서울 데이터끼리 비교하고, 소진공은 원래 247개 분류의 위치·구성 분석을 함께 살펴보는 데 사용합니다. [대응표](config/industry_crosswalk.csv)의 의미와 미연계 범위를 팀에서 확인해야 합니다.

### 5.4 32개 변수는 서로 독립인 32개 평가 기준이 아니다

32개에는 사업 특성뿐 아니라 로그 변환, 자료 분류 커버리지, 공간 배정 품질 지표도 포함되어 있습니다. 직장인구 비중과 상주인구 비중처럼 같은 분모에서 합이 1이 되는 변수, 개업·폐업 비율의 합과 차이처럼 수학적으로 연결된 변수도 있습니다. 이를 전부 같은 비중으로 점수화하면 같은 정보를 중복 반영할 수 있습니다.

또한 현재의 HHI는 **소분류 업종 구성의 집중도**입니다. 특정 회사의 시장점유율을 이용한 기업 독과점 지표나, 동일 업종 점포 사이의 경쟁 강도로 바로 해석하면 안 됩니다.

| 지표가 계산된 단위 | 변수 수 |
| --- | ---: |
| 분기×상권×서울 서비스업종 | 20 |
| 분기×상권 | 5 |
| 2025년 말 시점×상권 | 5 |
| 2025년 말 시점×상권×소진공소분류 | 1 |
| 연도×상권×업종 | 1 |

인구·시설·면적이 업종별 행에 반복되므로 업종 행을 더해 지역 인구나 시설 총량을 구하면 중복됩니다. 지역 수준의 확인에는 상권·분기 맥락 표를 사용합니다. 비율의 평균과 합계도 분모를 맞춘 뒤 정해야 합니다.

### 5.5 1년치 자료와 대리지표의 해석 범위를 지켜야 한다

- 소진공 점포는 12월 말 스냅숏입니다. Q4에만 연결했으며 Q1~Q3의 점포 구성을 복원하지 않았습니다.
- 지정 자료의 집객시설·직장인구·상주인구 총량은 네 분기 값이 같습니다. 반복값을 분기별 수요 성장으로 설명할 수 없습니다.
- 네 분기 매출이 모두 있는 상권·업종 조합은 20,098개입니다. 이 조합에만 계산한 변동계수는 2025년 내 변동의 기술통계이며 장기 안정성이나 폐업 위험 예측은 아닙니다.
- 유동인구 대비 매출은 서로 다른 집계량의 비율입니다. 고유 방문자와 구매자를 연결한 구매전환율이 아닙니다.
- 성별·연령별 분류 매출의 합은 총매출과 범위가 다를 수 있습니다. 이번 20·30대 매출 비중의 분모는 6개 연령대에 분류된 매출 합입니다.
- 개·폐업 신고 수는 기간 중 흐름이고 현재 점포 수는 관측 재고입니다. 나눈 값이 100%를 넘을 수 있으며 폐업 확률로 해석하지 않습니다.
- 결측 처리 규칙은 지표별로 읽어야 합니다. 분모가 0인 비율은 결측이지만, 관측된 점포 수가 0인 밀도는 0일 수 있고 `log(1+0)`도 0입니다. 정의표의 공통 결측 문구만으로 모든 변수를 같은 방식으로 처리하면 안 됩니다.
