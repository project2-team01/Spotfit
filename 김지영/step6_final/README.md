# STEP 6 EDA·시각화와 최종 산출물 대시보드 (2025년)

계획서 STEP 6의 시각화 7종을 만들고, 계획서 5장 '최종 산출물 구성'의 10개 항목 순서로 한 화면에 묶었습니다.
점수와 금융 MBTI는 **김지영 STEP 4 · 5 기준**을 그대로 씁니다([STEP 4](../step4_dashboard/README.md), [STEP 5](../step5_design/README.md)).

**바로 보기:** [report/SpotFit_최종산출물_대시보드_2025.html](report/SpotFit_최종산출물_대시보드_2025.html)을 브라우저로 여세요.
설치나 인터넷 연결이 필요 없습니다(약 3.9MB). 모든 화면, 업종 선택, 금융 MBTI 검사, 가중치 슬라이더가 파일 하나에서 동작합니다.

- **2025년 자료만 있어 성장성은 산출하지 않습니다.** 시각화 4(매출 성장률과 폐업률)는 매출 수준으로 바꿔 그렸습니다.
- **예산 적합성은 판단하지 않습니다.** 임대료 · 보증금 · 권리금 자료가 없습니다.
- 점수는 창업 결과를 예측하지 않습니다. 같은 업종의 다른 상권보다 지표가 상대적으로 낫다는 뜻일 뿐입니다.

## 화면 (계획서 5장 순서)

| 목차 | 내용 |
|:---|:---|
| 1. 분석 방향 요약 | 핵심 개수 6개, 계획서 목표 5개별 결과(완료 · 일부), 분석하면서 확인한 것 6가지, 이 결과로 말할 수 없는 것 |
| 2. 데이터셋과 다운로드 링크 | 9개 데이터셋의 행 · 열 수, 자료 기간, 실제 값 시점, 이번 분석에서 쓴 곳, 공식 링크 |
| 3. 데이터셋별 주요 컬럼 | 데이터셋을 고르면 원본 컬럼의 의미 · 단위 · 결측률과 STEP 2 표준 컬럼 이름 |
| 4. 전처리와 결합 구조 | 원본 9개 → STEP 2 · 3 표 6개 → STEP 4 · 5 → 최종 대시보드 흐름도, 표별 행 수 · 키, 처리 원칙 |
| 5. 파생변수 정의서 | STEP 3의 57개(산출 52 · 보류 5) + STEP 4 · 5 변수 6개. 단위 · 확보 여부 필터와 찾기 |
| 6. 상권 점수화 모델 | 점수 설계표, 가중치 슬라이더, 종합 점수 지도 · 순위표, 상권 상세(영역 막대와 업종 중앙값, 원값) |
| 7. 금융 MBTI 개인화 | 15문항 검사 또는 유형 직접 고르기 → 결과 · 가중치 → 적용하면 6장 표와 머리의 표시가 함께 바뀜. 유형이 맞는 상권 지도 · 표, L/V × E/P 산점도 |
| 8. EDA와 시각화 (STEP 6) | 시각화 7종. 카드마다 분석 목적 · 필요한 데이터 · 구현 방법 · 기대 인사이트와 '확인한 결과', 표로 보기 |
| 9. 폴더 구조 | 이 결과를 만드는 데 쓴 폴더와 다시 만드는 명령 |
| 10. 구현 로드맵 | STEP 1~6 상태, 자료가 더 있으면 할 수 있는 것, 팀이 정할 것, 박성은 님 통합본과 다른 점 |

맨 위의 **희망 업종**은 모든 화면에 함께 적용됩니다(기본 커피-음료).
점수는 서울 전체 같은 업종 기준이라, 화면에서 범위를 좁혀도 다시 계산하지 않습니다.
업종과 테마 선택은 브라우저에 저장해 다음에 열 때 그대로 보여 줍니다(저장이 막혀 있어도 화면은 동작합니다).

## 검증 (`test_final.py`, 14개 모두 통과)

1. 산출물이 지금 입력 · 화면 원본(27개 파일 sha256)으로 만든 것인지
2. 두 번 만들어도, 저장된 산출물과도 바이트까지 같은지
3. HTML 하나로 열리는지(외부 스크립트 · 스타일 · 요청 없음)
4. 개수: 상권 1,644 · 업종 100 · 점수 대상 20,522칸 · 유형 판정 1,534곳
5. 화면에 넣은 점수 · 원값이 STEP 4 점수표와 같은지(영역 점수는 반올림 없이 그대로)
6. 화면의 종합 점수 · 순위 계산이 STEP 4 `views.composite` · `order_rows`와 같은지(가중치 5가지, 102,610행)
7. 화면의 금융 MBTI 채점이 `mbti.py`와 같은지(완성 응답 32,768가지 전부 + 미완성 3,000가지)
8. 시각화 7의 유형별 상위 5곳이 Python 계산과 같은지(77개 업종)
9. 시각화 4의 순위상관이 Python과 같은지(53개 업종)
10. 시각화 2의 서울 매출 합계가 EDA 합계와 같은지
11. 시각화 5에서 상권마다 묶음 합 + 세부 미기재 = 집객시설 총수인지
12. 표준 컬럼 대응 · 데이터셋 · 파생변수 · 폴더 경로가 원본 문서와 맞는지
13. Chrome headless로 10개 화면이 콘솔 오류 없이 그려지는지
14. 검사 → 적용 → 6장 반영, 점수 없는 업종(예: DVD방) 안내가 동작하는지

node가 없으면 화면 계산 대조(6~9번)를, Chrome이 없으면 13 · 14번을 '건너뜀'으로 표시합니다(통과로 세지 않습니다). Chrome 경로는 `CHROME` 환경변수로 지정할 수 있습니다.
