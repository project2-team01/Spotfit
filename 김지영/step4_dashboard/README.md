# STEP 4 상권 비교 점수 대시보드 (2025년)

희망 업종 하나를 고르면, **서울의 같은 업종 상권끼리** 비교한 **업종 내 비교 점수**(0~100)를 보여 줍니다.
점수는 4개 영역으로 나뉩니다: 매출 잠재력 · 경쟁 · 안정성 · 수요.
STEP 5 **금융 MBTI**를 적용하면 유형이 맞는 상권만 보고, S/G 글자에 따라 가중치 기본값이 바뀝니다 ([STEP 5 설계](../step5_design/STEP5_금융MBTI_설계.md)).

- **2025년 자료만 있어 성장성은 산출하지 않습니다.**
- **예산 적합성은 판단하지 않습니다.** 임대료 · 보증금 · 권리금 자료가 없습니다.
- 이 점수는 창업 결과를 예측하지 않습니다. 점수가 높다는 것은 같은 업종의 다른 상권보다 지표가 상대적으로 낫다는 뜻일 뿐입니다.

## 실행 (팀 저장소 루트에서, uv만 있으면 됩니다)

```bash
uv run --project "김지영/step4_dashboard" python "김지영/step4_dashboard/build_scores.py"      # 1) 점수표 만들기 (몇 초)
uv run --project "김지영/step4_dashboard" python "김지영/step5_design/build_types.py"         #    + 금융 MBTI 상권 유형 (몇 초)
uv run --project "김지영/step4_dashboard" marimo run "김지영/step4_dashboard/app.py"            # 2) 대시보드 열기 (끄기: Ctrl+C)
open "김지영/step4_dashboard/report/04_상권비교점수_대시보드_2025.html"                           # 3) 설치 없이 보기 (윈도우: start)
```

검증 13개는 `uv run --project "김지영/step4_dashboard" python "김지영/step4_dashboard/test_step4.py"`로 돌립니다(약 4~5분, `--skip-app`이면 1분).
STEP 5 검증 13개는 `김지영/step5_design/test_step5.py`입니다.

**정적 HTML의 한계:** `report/04_상권비교점수_대시보드_2025.html`은 기본 조건(커피-음료, 기본 가중치)으로 찍은 스냅숏입니다.
필터와 슬라이더가 움직이지 않고, **처음 열리는 탭(상권 찾기)만 내용이 보입니다.** 금융 MBTI 검사, 다른 탭과 업종을 보려면 2번 명령으로 여세요.
html-wasm 방식은 같은 폴더의 `views.py`와 데이터 파일을 함께 담지 못해 쓰지 않았습니다.

## 화면

| 위치 | 내용 |
|:---|:---|
| 왼쪽 사이드바 | 금융 MBTI 적용(사용 안 함 · 검사 결과 · 직접 고르기, 유형이 맞는 상권만 보기), 희망 업종(기본 커피-음료), 자치구 · 상권 유형 필터, 영역별 가중치 슬라이더 4개 |
| 탭 1. 금융 MBTI 검사 | 15문항(순서 섞음, 글자 숨김), 결과(유형 · 몇 대 몇 · 경계 · 맞춰 볼 상권 유형 · 가중치), 상권 MBTI 유형 지도, L/V × E/P 사분면, 유형별 상권 수 |
| 탭 2. 상권 찾기 (처음 열리는 탭) | 비교 대상 · 점수 제외 상권 수, 종합 점수 지도(회색 = 점수 없음), 정렬 · 검색되는 비교표(금융 MBTI 적용 시 "MBTI 유형" · "유형 일치" 열). 점수를 만들 수 없는 업종이면 지도 대신 이유와 원값 표 |
| 탭 3. 상권 상세 | 영역 점수 막대와 서울 같은 업종 중앙값 선, 상권 MBTI 유형, 원값 비교표, 분기별 점포당 월매출 · 개폐업, 분기 매출 증감률(참고용), 데이터 시점 |
| 탭 4. 지표 분포와 자치구 비교 | 선택 업종의 원값 히스토그램(점수 대상/제외 구분, 점포 5개 기준선), 자치구별 종합 점수 중앙값 |
| 탭 5. 점수 기준과 한계 | STEP 4 · STEP 5 설계표, 제외 사유별 개수, 업종 100개 가능 여부, 영역 간 상관, 이 점수로 말할 수 없는 것 |

지도에서 상권을 클릭하거나 비교표 행 앞의 네모 칸을 누르면 상세 탭의 상권이 바뀝니다.
점수는 **서울 전체 같은 업종 기준**이라, 자치구 · 유형 필터를 바꿔도 다시 계산하지 않습니다(보여 주는 범위만 줄어듭니다).

## 점수 규칙 (2026-11-07 승인한 설계표)

| 영역 | 지표 | 방향 | 점수 있는 칸 |
|:---|:---|:---|---:|
| 매출 잠재력 | 점포당 월매출 `annual_monthly_sales_per_store` (4개 분기 매출이 모두 있는 칸만) | 높을수록 좋음 | 13,773 |
| 경쟁 [가정] | 같은 업종 점포 수 ÷ (유동인구 ÷ 1,000) | 낮을수록 좋음 | 20,522 |
| 안정성 (1년치·신뢰도 낮음) | 축소 추정 폐업률 = (연간 폐업 + α) ÷ (평균 점포 + α ÷ 업종 폐업률) × 100, α = 13.19 | 낮을수록 좋음 | 20,522 |
| 수요 [가정] | 면적당 유동 · 직장 · 상주인구의 업종 내 백분위 3개의 평균 | 높을수록 좋음 | 20,396 |

- **영역 점수:** 같은 업종의 점수 대상 상권 안에서 매긴 백분위입니다. 계산은 `rank(pct=True) × 100`이고, 동점이면 평균 순위를 씁니다.
- **종합 점수:** 자료가 있는 영역끼리 가중치를 다시 나눈 가중 평균입니다. 몇 개 영역으로 계산했는지 함께 표시합니다. 가중치가 모두 0이면 계산하지 않습니다.
- **대상:** 관광특구를 빼고, 연간 평균 점포 5개 이상인 칸만 점수를 매깁니다. 같은 업종의 비교 상권이 30곳 미만이면 그 업종은 점수를 만들지 않습니다(매출 영역에도 같은 30곳 기준).
- **결과:**
  - 상권×업종 점수 대상 20,522칸, 100개 업종 중 77개 업종에서 점수를 만들었습니다.
  - 매출 점수가 있는 업종은 53개입니다. 18개는 매출 미제공 업종이고, 6개는 매출 비교 상권이 부족합니다.
  - 제외된 칸은 관광특구 521, 평균 점포 0개 582, 점포 5개 미만(참고용) 55,824, 업종 비교 상권 부족 245칸입니다.
- **결측:** 매출이 없는 칸은 0으로 채우지 않고 "자료 없음"으로 둡니다. 수요 구성값이 하나라도 없으면 수요는 "자료 없음"입니다(126칸).

## 팀이 정해야 할 것 ([가정])

1. **기본 가중치:** 매출 30 · 경쟁 25 · 안정성 15 · 수요 30. 금융 MBTI를 적용하면 S 안정형 20 · 30 · 30 · 20, G 성장형 35 · 15 · 10 · 40, S/G 3:2 경계는 기본값입니다 (STEP 5 [가정]).
2. **경쟁 지표 정의:** 유동인구 대비 같은 업종 점포 수를 씁니다. 수요와 둘 다 유동인구를 써서 순위상관이 0.47입니다. 업종별로는 미용재료 0.82가 가장 높습니다.
3. **수요 구성:** 유동 · 직장 · 상주 인구를 같은 무게로 평균합니다. 직장인구와 상주인구는 서로 반대로 움직여(−0.55) 일부 상쇄됩니다.
4. **소표본 기준:** 점포 5개 · 비교 상권 30곳 기준은 팀 결정입니다. 이 기준을 바꿨을 때 순위가 얼마나 달라지는지는 아직 확인하지 않았습니다.
