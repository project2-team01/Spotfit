# Spotfit 상권 탐색기

희망 업종을 고르면 어느 상권을 살펴볼지, 그 근거를 얼마나 믿을 수 있는지 보여 주는 marimo 대시보드입니다. EDA에서 확인한 데이터의 한계를 화면 안에서 함께 보여 줍니다.

종합 점수나 추천 순위는 일부러 만들지 않았습니다. 가중치는 STEP 4에서 정할 일이고, 임대료·권리금·이익 자료가 없어 매출만으로 창업 적합성을 말할 수 없기 때문입니다.

## 실행

macOS에서는 [대시보드 실행.command](대시보드%20실행.command)를 더블클릭합니다. 터미널에서 실행하려면:

```bash
cd seoul-commercial-analysis
.venv/bin/marimo run 김지영/claude_dashboard/app.py --port 2730
```

브라우저에서 `http://localhost:2730`을 엽니다. 끄려면 터미널에서 `Ctrl+C`를 누릅니다. 포트가 사용 중이면 `--port 2731`처럼 바꿉니다.

`data/raw/`가 없어도 실행됩니다. 앱이 읽는 데이터는 이 폴더의 `data/`에 들어 있습니다(약 6MB). 패키지가 없다면:

```bash
cd seoul-commercial-analysis
python3 -m venv .venv  # 가상환경이 없을 때만
.venv/bin/python -m pip install -r 김지영/claude_dashboard/requirements.txt
```

## 화면

| 탭 | 할 수 있는 일 |
|---|---|
| 상권 찾기 | 업종·자치구·상권 유형·최소 점포 수로 좁혀 지도, 경쟁과 매출 산점도, 비교표를 봅니다. 지도 클릭, 표 선택, 검색 중 어느 쪽으로 골라도 아래 상세가 바뀝니다 |
| 업종 비교 | 100개 업종의 개업률과 폐업률, 선택 지표 순위, 전체 표를 봅니다 |
| 근거와 한계 | 숫자 정의, 매출 공개 규칙, 지표 신뢰도, 데이터별 실제 갱신 시점을 봅니다 |

상세에서는 분기별 점포당 월매출과 개업·폐업, 시간대·연령 구성을 서울 같은 업종과 비교합니다. 상권 수요는 기준 시점과 함께 보여 줍니다.

## 숫자를 읽는 기준

- 2025년 전체를 연간으로 묶어 봅니다. 관광특구는 다른 상권과 겹쳐 뺐습니다(1,644개 상권).
- **점포당 월매출**은 분기 추정매출 ÷ 점포 수 ÷ 3입니다. 카드사 자료 기반 추정치이며 개별 가게의 매출이나 이익이 아닙니다.
- **업종 내 지수**는 서울 같은 업종 중앙값 대비 배수입니다. 네 분기 매출이 있고 평균 점포 5개 이상인 상권만 계산하고, 그런 상권이 30곳 미만인 업종은 만들지 않습니다. STEP 3의 비교 규칙을 연간 단위에 적용한 것이며 지역 필터를 바꿔도 기준은 그대로입니다.
- **보정 폐업률**은 EDA 4.2의 축소 추정값입니다. 점포가 적을수록 업종 평균 쪽으로 당깁니다.
- **상권 폐업비**는 업종 구성으로 기대한 폐업 수 대비 실제 폐업 수입니다. 폐업 신호 라벨은 상권 점포 수로 나눈 신뢰도입니다.
- 매출이 없는 칸은 0으로 채우지 않습니다. 지도에서는 회색, 표에서는 빈칸입니다.
- 직장·상주인구와 집객시설은 2025년 안에서 값이 바뀌지 않아 기준 시점을 함께 표시합니다.
- 모든 관계는 상관이며 인과가 아닙니다.

## 기존 `dashboard/`와 다른 점

두 대시보드는 같은 STEP 2·3 데이터를 씁니다. 이 앱은 기존 폴더를 바꾸지 않습니다.

| | 기존 `dashboard/` | 이 앱 |
|---|---|---|
| 기본 단위 | 분기별 값 | 2025년 연간 값 |
| 지도 | 대표점, 매출 유무 구분 | 상권 경계를 업종 내 지수로 채색, 클릭으로 선택 |
| 폐업 지표 | 건수와 원값 | 축소 추정, 상권 폐업비, 신뢰도 라벨 |
| 데이터 시점 | 데이터 확인 탭의 설명 | 상세와 근거 탭에 값이 바뀐 분기를 표시 |
| 읽는 데이터 | STEP 2·3 원본 압축 CSV | 요약 데이터 약 6MB |
| 그 밖 | EDA 그림 모음, 파생변수 사전, 요일별 구성 | 업종 전체 비교 |

## 데이터 다시 만들기

STEP 2·3 산출물이나 EDA 규칙이 바뀌면 다시 만듭니다. `step2_3/data/`와 `data/raw/`가 필요합니다.

```bash
cd seoul-commercial-analysis
.venv/bin/python 김지영/claude_dashboard/build_data.py
```

## 파일

| 파일 | 내용 |
|---|---|
| `app.py` | marimo 화면과 반응형 연결 |
| `views.py` | 데이터 조회와 차트. marimo 없이 테스트할 수 있습니다 |
| `build_data.py` | STEP 2·3 산출물과 상권 경계로 `data/`를 만듭니다 |
| `test_dashboard.py` | EDA 수치 재현, 결측 보존, 필터, 빈 결과, 매출 미제공 업종을 검증합니다 |
| `data/` | 앱이 읽는 요약 데이터 |

## 검증

```bash
.venv/bin/marimo check 김지영/claude_dashboard/app.py
.venv/bin/python 김지영/claude_dashboard/test_dashboard.py
```

Chrome에서 직접 확인한 것: 세 탭의 주요 차트가 그려지는 것, 지도 클릭으로 아래 상세가 바뀌는 것, 업종 비교 탭에서 필터를 바꿔도 탭이 유지되는 것. 확인 환경의 헤드리스 브라우저가 매우 느려 일반 브라우저에서의 로딩 시간은 재지 못했습니다.
