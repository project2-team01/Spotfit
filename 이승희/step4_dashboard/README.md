# STEP 4 상권 비교 점수 대시보드 (2025년)

희망 업종을 고르면 **서울의 같은 업종 상권끼리** 4개 영역(매출 잠재력 · 경쟁 · 안정성 · 수요)을 비교한 점수를 보여 주는 marimo 대시보드입니다. 2026-11-05 팀 결정 사항을 따릅니다.

- 이 점수는 창업 성공 가능성이나 수익을 뜻하지 않습니다.
- **성장성은 2025년 자료만 있어 산출하지 않습니다.**
- 예산 적합성은 판단하지 않습니다.

## 실행 (팀 저장소 루트에서)

[uv](https://docs.astral.sh/uv/)만 있으면 됩니다. 윈도우와 맥 모두 됩니다. 원본 데이터(`data/raw/`)는 필요 없습니다.

```bash
uv run --project "이승희/step4_dashboard" marimo run "이승희/step4_dashboard/app.py"         # 대시보드 열기
uv run --project "이승희/step4_dashboard" python "이승희/step4_dashboard/build_scores.py"     # 점수표 다시 만들기
uv run --project "이승희/step4_dashboard" python "이승희/step4_dashboard/test_step4.py"      # 검증 (약 1분)
```

- 첫 실행 때 uv가 필요한 패키지를 자동으로 설치합니다.
- 대시보드는 브라우저에서 열립니다. 끄려면 터미널에서 `Ctrl+C`를 누릅니다.
- **설치 없이 보기:** [report/04_상권비교점수_대시보드_2025.html](report/04_상권비교점수_대시보드_2025.html)을 브라우저로 열면 됩니다. 정적 스냅숏이라 필터가 움직이지 않고, 첫 탭(커피-음료 기본값)만 내용이 보입니다.

## 화면

| 탭 | 내용 |
| :--- | :--- |
| 상권 찾기 | 업종·자치구·상권 유형 필터, 가중치 슬라이더, 수요의 주 고객층 선택, 종합 점수 지도와 비교표, 경쟁·수요 겹침 확인 |
| 상권 상세 | 4개 영역 점수 막대, 원값과 서울 같은 업종 중앙값, 분기별 점포당 월매출·개폐업, 분기 매출 증감률(참고용) |
| 지표 분포와 자치구 비교 | 선택 업종의 지표 분포 히스토그램, 자치구별 종합 점수 중앙값 |
| 점수 기준과 한계 | 점수 설계표, 제외 사유별 개수, 영역 간 상관, 이 점수로 말할 수 없는 것 |

## 점수 규칙

| 영역 | 지표 | 방향 |
| :--- | :--- | :--- |
| 매출 잠재력 | 점포당 월매출 (4개 분기 매출이 모두 있는 칸만) | 높을수록 좋음 |
| 경쟁 [가정] | 유동인구 1,000명당 같은 업종 점포 수 | 낮을수록 좋음 |
| 안정성 | 축소 추정 폐업률 (분모 = 4개 분기 평균 점포). 1년치라 신뢰도 낮음 | 낮을수록 좋음 |
| 수요 [가정] | 면적당 유동인구·직장인구·상주인구. 주 고객층 선택 가능 | 높을수록 좋음 |

**공통 규칙**
- 영역 점수는 서울 같은 업종 상권 안의 백분위(0~100)입니다.
- 종합 점수는 자료가 있는 영역끼리 가중치를 다시 나눈 가중 평균입니다.
- 기본 가중치는 매출 30 · 경쟁 25 · 안정성 15 · 수요 30이고, 팀이 확정하지 않은 [가정]입니다.

**대상 조건 (팀 결정)**
- 관광특구는 제외합니다.
- 연간 평균 점포 5개 이상인 칸만 점수를 매깁니다.
- 같은 업종에서 비교할 상권이 30곳 미만이면 그 업종은 점수를 만들지 않습니다.

**결측 처리**
- 매출이 없는 칸은 0으로 채우지 않고 "자료 없음"으로 둡니다.
- 분기 매출 증감률은 점수에 넣지 않습니다.

**결과 규모**
- 관광특구를 뺀 상권×업종 76,591칸 중 20,522칸에 점수가 있습니다.
- 100개 업종 중 77개 업종에서 점수를 만들 수 있고, 그중 53개 업종은 매출 영역까지 있습니다.

## 읽을 때 주의할 점

- **필터와 점수:** 점수는 서울 전체 같은 업종 기준입니다. 자치구나 유형 필터를 바꿔도 다시 계산하지 않습니다.
- **경쟁과 수요의 겹침:** 둘 다 유동인구를 써서 일부 겹칩니다(상관 0.47). "상권 찾기" 탭에서 경쟁을 뺐을 때 상위 상권이 얼마나 바뀌는지 확인할 수 있습니다.
- **직장인구와 상주인구:** 두 값은 서로 반대로 움직입니다(상관 −0.55). 그래서 수요 영역에 주 고객층 선택을 두었습니다.
- **값이 바뀌지 않는 자료:** 직장인구·상주인구·집객시설은 2025년 안에서 값이 바뀌지 않습니다.
- **해석:** 모든 관계는 상관이며 인과가 아닙니다.
