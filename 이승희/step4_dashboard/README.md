# STEP 4 상권 비교 점수 대시보드 (2025년)

희망 업종을 고르면 **서울의 같은 업종 상권끼리** 4개 영역(매출 잠재력 · 경쟁 · 안정성 · 수요)을 비교한 점수를 보여 주는 marimo 대시보드입니다. 2026-11-05 팀 결정 사항을 따릅니다.

- 이 점수는 창업 성공 가능성이나 수익을 뜻하지 않습니다.
- **성장성은 2025년 자료만 있어 산출하지 않습니다.**
- 예산 적합성은 판단하지 않습니다.

## 실행 (팀 저장소 루트에서)

[uv](https://docs.astral.sh/uv/)만 있으면 됩니다. 윈도우와 맥 모두 됩니다. 원본 데이터(`data/raw/`)는 필요 없습니다.

```bash
uv run --project "이승희/step4_dashboard" marimo run "이승희/step4_dashboard/app.py"         # 대시보드 열기
uv run --project "이승희/step4_dashboard" python "이승희/step4_dashboard/build_scores.py"     # 점수표 다시 만들기
uv run --project "이승희/step4_dashboard" python "이승희/step4_dashboard/test_step4.py"      # 검증 13개 (약 1분)
uv run --project "이승희/step4_dashboard" python "이승희/step4_dashboard/precompute_maps.py" # 업종별 지도 미리 저장 (약 1분, 선택)
```

**지도 저장(캐시)으로 빠르게 열기**
- 지도는 만들 때마다 약 1초가 걸립니다. 그래서 한 번 만든 지도는 `data/map_cache/`에 저장해 두고, 다음부터 불러옵니다 (저장 파일 약 0.3초, 같은 실행 중 다시 볼 때 약 0.2초).
- **미리 계산:** `precompute_maps.py`를 실행하면 100개 업종의 첫 화면 지도를 미리 저장합니다 (약 40초, 약 28MB).
- **새 조합:** 가중치·자치구·유형·고른 상권 등 처음 보는 조합은 처음 볼 때 만들어 저장하고, 다음부터 불러옵니다.
- 지도 위 "지도 준비" 문구에서 불러왔는지, 새로 만들었는지와 걸린 시간을 볼 수 있습니다.
- 점수표·경계 데이터나 `views.py`가 바뀌면 예전 저장본은 자동으로 쓰지 않습니다. `data/map_cache/`는 Git에 올리지 않고, 지워도 필요할 때 다시 만들어집니다.
- 브라우저가 지도를 그리는 시간은 저장으로 줄지 않습니다.

- 첫 실행 때 uv가 필요한 패키지를 자동으로 설치합니다.
- 이 폴더의 `.python-version`이 Python 3.12를 고릅니다. 다른 버전(예: 3.15)을 고르면 marimo가 쓰는 pyyaml 설치가 실패할 수 있습니다.
- 대시보드는 브라우저에서 열립니다. 끄려면 터미널에서 `Ctrl+C`를 누릅니다.
- **설치 없이 보기:** [report/04_상권비교점수_대시보드_2025.html](report/04_상권비교점수_대시보드_2025.html)을 브라우저로 열면 됩니다. 정적 스냅숏이라 필터가 움직이지 않고, 첫 탭(커피-음료 기본값)만 내용이 보입니다. 픽셀 지도의 구 클릭 확대는 스냅숏에서도 됩니다.
- 스냅숏 다시 만들기 (팀 저장소 루트): `uv run --project "이승희/step4_dashboard" marimo export html --no-include-code "이승희/step4_dashboard/app.py" -o "이승희/step4_dashboard/report/04_상권비교점수_대시보드_2025.html"`

**도트 디자인**
- 크림 바탕 · 파랑/노랑/초록 색, 큰 제목 `SPOTFIT`과 그림만 도트, 본문은 맑은 고딕입니다. STEP 5와 같은 [../pixel_theme/](../pixel_theme/README.md)을 씁니다.
- 탭·숫자 카드 모양은 `marimo run`(앱 모드)과 정적 스냅숏에서만 바뀝니다. `marimo edit`(편집 모드)에서는 marimo 기본 모양으로 보입니다(보안상 marimo가 편집 모드에서 스크립트를 넣지 않음).
- 어두운 화면에서는 크림 바탕 대신 marimo 기본 어두운 색을 씁니다.

## 화면

| 탭 | 내용 |
| :--- | :--- |
| 상권 찾기 | 업종·자치구·상권 유형 필터, 가중치 슬라이더, 수요의 주 고객층 선택, 자치구 픽셀 지도, 종합 점수 지도 2종, 비교표, 경쟁·수요 겹침 확인 |
| 상권 상세 | 4개 영역 점수 막대, 후보 상권 2~4곳 비교(레이더 차트·상권별 막대 서브플롯), 원값과 서울 같은 업종 중앙값, 분기별 점포당 월매출·개폐업, 분기 매출 증감률(참고용) |
| 지표 분포와 자치구 비교 | 선택 업종의 지표 분포 히스토그램, 자치구별 종합 점수 중앙값 |
| 점수 기준과 한계 | 점수 설계표, 제외 사유별 개수, 영역 간 상관, 이 점수로 말할 수 없는 것 |

**자치구 지도 (맨 위): 서울은 도트, 구를 누르면 상권 상세**
- **서울 전체 화면 (도트)**
  - 구 색 = 구 중앙값과 **서울 같은 업종 중앙값의 차이**입니다. 비슷(±2점 안)은 크림, 높으면 파랑, 낮으면 노랑이고 2~5점, 5점 넘게로 진해집니다. 경계 ±2·±5점은 [가정]입니다. 구 이름표 숫자 = 차이입니다.
  - 오른쪽 위 **구 색 기준** 버튼: 종합 / 매출 / 경쟁 / 안정성 / 수요 / 상위 10% 상권 수. 누르면 색·이름표·설명·범례가 함께 바뀝니다. 매출 자료가 없는 업종에는 매출 버튼이 없습니다.
  - 상위 10% 상권 수 = 서울 같은 업종 종합 점수 상위 10% 안에 드는 상권이 그 구에 몇 곳인지입니다. 구 면적이 클수록 많아지기 쉽습니다.
  - 점수 상권이 10곳 미만[가정]인 구는 흐린 색·점선·숫자 옆 `*`(참고용)입니다. 절반 넘는 구가 참고용이면 범례에 경고가 뜹니다.
  - 마우스를 올리면 구가 떠오르고 구 중앙값·서울 중앙값 대비 차이·25개 구 중 순위가 나옵니다. 빨간 핀 번호는 종합 점수 상위 10곳입니다. 이름표를 핀보다 위에 그리므로 가려진 핀은 마우스를 올리면 앞으로 나옵니다.
- **구를 클릭하면 (상권 상세)**
  - 부드럽게 확대되며 배경 지도(Esri 회색 지도) 위에 **그 구의 상권**을 아래 상권 지도와 같은 색(종합 점수, 진할수록 높음)으로 그립니다. 구 테두리는 실제 자치구 경계입니다.
  - 왼쪽 상자에 구 점수 상권 수·중앙값·서울 중앙값 대비 차이·구 순위와 상위 5곳(지도의 검은 번호)이 나옵니다.
  - **상권을 클릭하거나 상위 5곳 목록을 누르면** 상세 카드가 열립니다: 종합 점수·서울 순위, 4개 영역 막대(50점 점선), 원값과 서울 같은 업종 중앙값(점포당 월매출·점포 밀도·보정 폐업률·면적당 유동인구·평균 점포 수).
  - 제목 상자의 '서울 전체' 또는 '← 서울 전체'로 돌아갑니다. 고른 기준은 그대로 유지됩니다. 다른 구를 바로 눌러 옮겨 갈 수도 있습니다.
- 가중치·자치구·유형·주 고객층을 바꾸면 다시 그립니다(처음 약 0.5초, 같은 조합은 메모리에서 바로). 대시보드를 켠 뒤 처음 그릴 때는 folium을 불러오느라 몇 초 더 걸립니다.
- 칸 출력 한도(8MB) 때문에 아래 지도 2종과 다른 칸에 둡니다. 상권이 가장 많은 업종에서 약 3.4MB입니다.
- 이 지도를 클릭해도 상세 탭의 상권은 바뀌지 않습니다. 상권을 고르려면 아래 Altair 지도를 씁니다.
- 구 상세 화면의 배경 지도와 글꼴은 인터넷 연결이 필요합니다.

**상권 지도 2종 (나란히 표시)**
- **Plotly 지도:** 실제 지도(CARTO 배경) 위에 상권을 그립니다. 마우스 휠로 확대·축소하고 끌어서 이동합니다. 배경 지도는 인터넷 연결이 필요합니다. 가중치를 바꿔도 보던 위치를 유지하고, 업종·자치구·유형을 바꾸면 처음 위치로 돌아갑니다.
- **Altair 지도:** 상권을 클릭하면 상권 상세 탭이 그 상권으로 바뀝니다. 확대·이동은 되지 않습니다.
- **두 지도 공통:**
  - 마우스를 올리면 상권 이름·자치구, 종합 점수와 서울 같은 업종 안 순위, 4개 영역 점수가 짧게 나옵니다.
  - 검은 번호는 지금 보이는 범위의 상위 10곳입니다. 진한 노란 테두리는 지금 고른 상권입니다.
  - 점수가 없는 상권은 옅은 회색입니다.

## 점수 규칙

| 영역 | 지표 | 방향 |
| :--- | :--- | :--- |
| 매출 잠재력 | 점포당 월매출 (4개 분기 매출이 모두 있는 칸만) | 높을수록 좋음 |
| 경쟁 [가정] | 유동인구 1,000명당 같은 업종 점포 수 | 낮을수록 좋음 |
| 안정성 | 축소 추정 폐업률 (분모 = 4개 분기 평균 점포). 1년치라 신뢰도 낮음 | 낮을수록 좋음 |
| 수요 [가정] | 면적당 유동인구·직장인구·상주인구. 기본은 세 값이 **모두 있을 때만** 평균(2026-11-19 박성은 통합 기준 v1·김지영 방식). 주 고객층 선택 가능 | 높을수록 좋음 |

**공통 규칙**
- 영역 점수는 서울 같은 업종 상권 안의 백분위(0~100)입니다.
- 종합 점수는 자료가 있는 영역끼리 가중치를 다시 나눈 가중 평균입니다.
- 기본 가중치는 매출 30 · 경쟁 25 · 안정성 15 · 수요 30이고, 팀이 확정하지 않은 [가정]입니다.

**대상 조건 (팀 결정)**
- 관광특구는 제외합니다.
- 연간 평균 점포 5개 이상인 칸만 점수를 매깁니다.
- 같은 업종에서 비교할 상권이 30곳 미만이면 그 업종은 점수를 만들지 않습니다.

**결측 처리**
- 매출이 없는 칸은 0으로 채우지 않고 "자료 없음"으로 둡니다.
- 분기 매출 증감률은 점수에 넣지 않습니다.

**결과 규모**
- 관광특구를 뺀 상권×업종 76,591칸 중 20,522칸에 점수가 있습니다.
- 100개 업종 중 77개 업종에서 점수를 만들 수 있고, 그중 53개 업종은 매출 영역까지 있습니다.

## 읽을 때 주의할 점

- **필터와 점수:** 점수는 서울 전체 같은 업종 기준입니다. 자치구나 유형 필터를 바꿔도 다시 계산하지 않습니다.
- **경쟁과 수요의 겹침:** 둘 다 유동인구를 써서 일부 겹칩니다(상관 0.47). "상권 찾기" 탭에서 경쟁을 뺐을 때 상위 상권이 얼마나 바뀌는지 확인할 수 있습니다.
- **직장인구와 상주인구:** 두 값은 서로 반대로 움직입니다(상관 −0.55). 그래서 수요 영역에 주 고객층 선택을 두었습니다.
- **값이 바뀌지 않는 자료:** 직장인구·상주인구·집객시설은 2025년 안에서 값이 바뀌지 않습니다.
- **해석:** 모든 관계는 상관이며 인과가 아닙니다.
