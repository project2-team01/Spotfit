# 지도 디자인 시안 (folium 픽셀 아트)

대시보드 지도를 도트(픽셀 아트) 느낌으로 그린 디자인 시안입니다. 데이터는 STEP 4 **커피-음료** 종합 점수(2025년)입니다.

**채택안은 STEP 4·STEP 5 대시보드에 들어갔습니다(2026-11-17).** 지도를 그리는 코드는 [../pixel_theme/pixel_map.py](../pixel_theme/pixel_map.py)로 옮겨 대시보드와 이 시안이 함께 씁니다.

## 먼저 볼 파일 (채택안, 대시보드에 들어감)

**[folium_pixel_gu_score_map_sample.html](folium_pixel_gu_score_map_sample.html)**: 브라우저로 열면 됩니다.
- 처음 화면은 25개 자치구를 구별 점수 중앙값 순위(5개 구씩 5단계)로 칠한 지도입니다. 구 이름표 숫자가 중앙값입니다.
- **구를 클릭하면** 배경 지도 위에 그 구의 상권 경계가 종합 점수 색(진할수록 높음)으로 그려지고, 왼쪽에 상위 5곳(서울 순위 포함)이 나옵니다. "← 서울 전체"로 돌아갑니다. (2026-11-17에 약 400m 칸에서 실제 상권 경계로 바꿈)
- 서울 밖(경기·인천)은 이름 없는 도트 실루엣, 한강은 연한 파란 도트입니다. 대시보드 지도 틀이 가로로 길어 실루엣 범위를 동서로 넓혔습니다(경도 126.15~127.85, 위도 37.20~37.95, 시·군 34개).
- 두 화면의 색 기준이 다릅니다. 처음 화면은 구끼리의 순위, 상세 화면은 상권 점수 자체(0~100 연속 색)입니다.

### 업그레이드 시안 (2026-11-18, STEP 4·5 대시보드에도 적용)

`folium_pixel_gu_score_map.py`가 `upgrade=True`로 그립니다.

1. **서울 전체(도트) 화면**
   - 구 색 = 서울 같은 업종 중앙값과의 차이입니다. 비슷(±2점 안)은 크림, 높으면 파랑, 낮으면 노랑이고 2~5점, 5점 넘게로 진해집니다. 경계 ±2·±5점은 [가정]입니다.
   - 구 이름표 숫자 = 차이입니다(예: `+2.2`). 마우스를 올리면 25개 구 중 순위와 서울 중앙값 대비 차이가 나옵니다. 범례에 단계별 구 수와 가장 높은 구와 낮은 구의 차이를 적습니다.
   - 점수 상권이 10곳 미만[가정]인 구는 흐린 색·점선·숫자 옆 `*`로 '참고용'을 표시합니다. 절반 넘는 구가 참고용이면 범례에 "구끼리 비교하기 어렵습니다"라는 경고가 뜹니다.
2. **구 상세 화면**
   - 상권을 클릭하거나 왼쪽 상위 5곳 목록을 누르면 상세 카드가 나옵니다. 카드에는 종합 점수·서울 순위, 4개 영역 막대(50점 점선), 원값과 서울 같은 업종 중앙값 비교(점포당 월매출·점포 밀도·보정 폐업률·면적당 유동인구·평균 점포 수)가 들어 있습니다.
   - 구 테두리는 실제 자치구 경계(`seoul_gu_real.geojson`)로 그립니다. 서울 전체 화면은 그대로 도트입니다.

3. **기준 바꾸기·보기 효과** (2026-11-18)
   - 서울 전체 화면 오른쪽 위 **구 색 기준** 버튼: 종합 / 매출 / 경쟁 / 안정성 / 수요 / 상위 10% 상권 수. 누르면 구 색·이름표 숫자·마우스 설명·범례가 함께 바뀝니다.
     - 영역 점수 4개는 종합과 같은 방식(서울 같은 업종 중앙값과의 차이)입니다. 매출 자료가 없는 업종은 매출 버튼이 나오지 않습니다.
     - 상위 10% 상권 수 = 서울 같은 업종 종합 점수 상위 10% 안에 드는 상권이 그 구에 몇 곳인지입니다. 구 면적이 클수록 많아지기 쉽습니다.
   - 구에 마우스를 올리면 그림자와 함께 살짝 떠오릅니다. 구를 누르면 부드럽게 날아가며 확대됩니다.
   - 제목 상자에 위치(서울 전체 › 강남구)가 나오고, '서울 전체'를 눌러 돌아갑니다. 돌아와도 고른 기준이 유지됩니다.
   - 구 이름표를 빨간 핀보다 위에 그려 이름이 가려지지 않게 했습니다. 가려진 핀은 마우스를 올리면 맨 앞으로 나옵니다.

## 종합 대시보드 샘플 (김지영 뼈대, 2026-11-18)

[integrated_dashboard/](integrated_dashboard/README.md): 김지영 STEP 4·5 대시보드를 복사해 '상권 찾기' 탭에 이 지도를 넣은 샘플입니다. 김지영 동의 전이라 김지영 폴더는 바꾸지 않았습니다.

## 다시 만들기 (팀 저장소 루트에서)

folium·shapely는 이제 STEP 4 환경에 들어 있습니다. `--with`는 그대로 둬도 됩니다.

```bash
uv run --project "이승희/step4_dashboard" python "이승희/design_samples/folium_pixel_gu_score_map.py"   # 채택안 (outside_pixel.geojson을 지우면 실루엣도 다시 만듦)
UV_PYTHON=3.12 uv run --project "이승희/step4_dashboard" --with folium --with shapely python "이승희/design_samples/folium_pixel_map.py"            # 400m 칸 (뒤에 3을 붙이면 1.2km 칸)
UV_PYTHON=3.12 uv run --project "이승희/step4_dashboard" --with folium --with shapely python "이승희/design_samples/folium_pixel_gu_map.py"         # 자치구 지도
```

- 경계 모양은 통계청 행정동 경계(2025-12-31, `HangJeongDong_ver20251231.geojson`)에서 만들어 아래 파일에 저장해 두었습니다. 이 파일들이 있으면 원본 없이 다시 그릴 수 있습니다.
  - `seoul_gu_pixel.geojson`: 25개 자치구 도트 모양과 한강 칸
  - `outside_pixel.geojson`: 서울 주변 시·군 도트 실루엣. 다시 만들 때 원본 위치는 `이승희/data/raw/geo/`, 팀 저장소 옆 `PJT2-SpotFit/data/raw/geo/`, 또는 환경변수 `SPOTFIT_RAW_GEO` 순서로 찾습니다.
  - `seoul_pixel_outline.geojson`: 서울 바깥 테두리
  - `seoul_gu_real.geojson`: 실제 자치구 경계 (구 상세 화면 테두리. 행정동 경계를 구별로 합치고 약 20m로 단순화, 47KB)
- 한강은 공개 지도 자료를 받지 못해, 한강 북쪽 구(마포·용산·성동·광진)와 남쪽 구가 맞닿는 경계선으로 그렸습니다. 서울 밖으로 이어지는 양 끝은 없습니다.

## 한계

- 대시보드 안에서도 구 클릭 확대가 됩니다(지도를 marimo의 iframe으로 넣음). 다만 이 지도를 클릭해도 대시보드의 다른 칸(상세 탭 등)은 바뀌지 않습니다.
- 구 단위 색은 구 하나를 중앙값 하나로 요약한 것이라 구 안의 차이는 클릭해서 봐야 합니다.
