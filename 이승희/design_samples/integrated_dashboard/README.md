# [샘플] 종합 대시보드(김지영 뼈대) + 이승희 자치구 지도

팀 결정 7.11 "대시보드 하나로 통합(김지영 뼈대)"이 어떤 모습일지 보기 위한 **샘플**입니다. 김지영 동의 전이라 김지영 폴더는 바꾸지 않았습니다.

- `app.py`: `김지영/step4_dashboard/app.py`(STEP 4 + STEP 5 금융 MBTI 연결)를 복사해 **'상권 찾기' 탭 맨 위에 이승희 자치구 지도 칸 하나만** 더했습니다. 나머지 화면은 김지영 대시보드와 같습니다.
- `jy_pixel.py`: 김지영 표의 열 이름을 이승희 지도(`../../pixel_theme/pixel_map.py`, `upgrade=True`)에 맞게 바꿔 넘깁니다. 점수는 다시 계산하지 않고, 김지영 화면 왼쪽 가중치로 계산한 종합 점수를 그대로 씁니다.

## 실행 (팀 저장소 루트에서)

```bash
uv run --project "이승희/step4_dashboard" marimo run "이승희/design_samples/integrated_dashboard/app.py"
```

- 실행 환경은 이승희 STEP 4 환경을 씁니다(marimo·pandas 등 버전이 김지영 환경과 같고, folium·shapely가 들어 있음). 김지영 폴더에 실행 환경(`.venv`)을 만들지 않기 위해서입니다.
- 김지영 폴더 파일(`views.py`, `mbti.py`, `data/`, `../step5_design/data/`)은 읽기만 합니다. 불러올 때 김지영 폴더에 `__pycache__`가 생기지 않게 했습니다.
- 김지영 STEP 4 데이터(`김지영/step4_dashboard/data/`)가 있어야 합니다(팀 저장소에 올라 있음).

**설치 없이 보기:** [종합대시보드_샘플_2025.html](종합대시보드_샘플_2025.html)을 브라우저로 엽니다(약 6.6MB). 정적 스냅숏이라 기본 조건(커피-음료, 기본 가중치, 금융 MBTI 사용 안 함)의 '상권 찾기' 탭만 내용이 있고, 왼쪽 조건을 바꿔도 다시 계산하지 않습니다. 새 지도 안의 기준 버튼·구 클릭·상권 카드는 됩니다. 배경 지도·글꼴은 인터넷이 필요합니다.

다시 만들기 (팀 저장소 루트): `uv run --project "이승희/step4_dashboard" marimo export html --no-include-code "이승희/design_samples/integrated_dashboard/app.py" -o "이승희/design_samples/integrated_dashboard/종합대시보드_샘플_2025.html"`
(만들기 전에 `이승희/design_samples/integrated_dashboard/__marimo__/session/`의 저장 파일을 지우세요. `marimo run`으로 띄웠을 때 바꾼 화면 상태가 남아 있으면 그 상태로 내보내집니다.)

## 새 지도에서 할 수 있는 것

- 서울 전체(도트): 구 색 = 구 중앙값과 서울 같은 업종 중앙값의 차이, 구 색 기준 버튼(종합·매출·경쟁·안정성·수요·상위 10% 상권 수), 표본 적은 구 표시
- 구를 클릭하면: 배경 지도 위 그 구의 상권(점수 색), 실제 구 경계, 상위 5곳, 상권을 누르면 4개 영역 점수·원값 카드
- 자세한 설명: [../README.md](../README.md)

## 한계와 확인할 점

- **김지영 동의 전 샘플**입니다. 실제 통합은 김지영과 방식(복사본이 아니라 김지영 앱에 칸을 더할지 등)을 정한 뒤 진행합니다.
- 이 지도를 클릭해도 김지영 대시보드의 '상권 상세' 탭은 바뀌지 않습니다(아래 김지영 지도를 쓰면 바뀜).
- 금융 MBTI '유형이 맞는 상권만 보기'를 켜면 지도도 그 상권만으로 칠합니다. 순위·중앙값 기준은 서울 같은 업종 전체입니다.
- 김지영 대시보드와 이승희 STEP 4는 같은 팀 결정을 따르지만 세부 계산이 조금 달라 숫자가 다를 수 있습니다. 예: 커피-음료 점포당 월매출의 서울 중앙값이 김지영 483만 원, 이승희 465만 원입니다. STEP 4 결과물 통일(팀 회의 안건)과 함께 정해야 합니다.
- 김지영 대시보드 원본이 바뀌면 이 복사본 `app.py`는 따라 바뀌지 않습니다.
