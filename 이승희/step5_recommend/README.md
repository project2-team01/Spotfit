# STEP 5 금융 MBTI 상권 추천 (2025년)

나의 창업 성향 세 가지(**주 고객 · 가격대 · 상권 변화**)와 희망 업종을 고르면, 성향이 맞는 상권을 STEP 4 비교 점수 순서로 보여 주는 marimo 대시보드입니다.

- 상권 변화 축은 **'G 성장형' 대신 'D 역동형'**을 씁니다(2026-11-12 이승희 제안). 성장은 작년 자료가 있어야 알 수 있지만, 변화가 많은지 적은지는 2025년 자료로도 알 수 있습니다.
- 유형과 점수는 창업 성공 가능성이나 수익을 뜻하지 않습니다.
- 예산 적합성은 판단하지 않습니다. 비용 자료(임대료·보증금·권리금·시설비)가 없습니다(팀 결정 7.10).

## 실행 (팀 저장소 루트에서)

[uv](https://docs.astral.sh/uv/)만 있으면 됩니다. 원본 데이터(`data/raw/`)는 필요 없습니다.

```bash
uv run --project "이승희/step5_recommend" marimo run "이승희/step5_recommend/app.py"          # 대시보드 열기
uv run --project "이승희/step5_recommend" python "이승희/step5_recommend/build_types.py"      # 유형표 다시 만들기
uv run --project "이승희/step5_recommend" python "이승희/step5_recommend/test_step5.py"       # 검증 19개 (약 25초)
```

- 이 폴더의 `.python-version`이 Python 3.12를 고릅니다. 컴퓨터에 Python 3.15만 있으면 marimo가 쓰는 pyyaml 설치가 실패합니다.
- STEP 4 점수표나 2단계 마트가 유형표를 만든 뒤에 바뀌면, 대시보드 맨 위에 빨간 경고가 뜹니다. 그때는 `build_types.py`를 다시 실행합니다.
- **설치 없이 보기:** [report/05_금융MBTI_상권추천_2025.html](report/05_금융MBTI_상권추천_2025.html)을 브라우저로 엽니다. 정적 스냅숏이라 선택이 움직이지 않고, 첫 탭(커피-음료, 모든 축 상관없음)만 보입니다.

## 세 축

| 축 | 글자 | 쓰는 값 | 판정 | 단위 |
| :--- | :--- | :--- | :--- | :--- |
| 주 고객 [가정] | L 생활형 / V 방문형 | 주민 ÷ (주민 + 직장인) | 0.55 초과 L, 0.45 미만 V, 그 사이 보류 | 상권 |
| 가격대 [가정] | E 실속형 / P 프리미엄형 | 결제 1건당 금액의 같은 업종 안 백분위 | 45 미만 E, 55 초과 P, 그 사이 보류 | 상권×업종 |
| 상권 변화 | S 안정형 / D 역동형 | 서울시 상권변화지표 2025년 4분기 | 정체 → S, 다이나믹 → D, 상권확장·상권축소 → 중간(보류) | 상권 |

- **L/V:** 주민·직장인 수는 2025년 안에서 값이 바뀌지 않는 자료입니다(STEP 4와 같음). 실제 통계 기준 시점은 확인하지 못했습니다.
- **E/P:** STEP 4 점수 대상 중 4개 분기 매출이 모두 있고, 네 분기 매출이 똑같지 않은(품질 확인 필요) 상권끼리 비교합니다. 비교 상권이 30곳 미만인 업종은 판정하지 않습니다.

**상권변화지표란?** 서울시가 상권마다 두 값을 서울 평균과 비교해 4가지로 나눈 공식 지표입니다.
- 지금 영업 중인 가게들이 평균 몇 달째 영업 중인지 (2025년 4분기 서울 평균 115개월)
- 문을 닫은 가게들이 평균 몇 달 영업하고 닫았는지 (서울 평균 53개월)

| 서울시 유형 | 두 값 | 뜻 | 이 대시보드 |
| :--- | :--- | :--- | :--- |
| 정체 (HH) | 둘 다 평균보다 김 | 가게가 오래 버팀 | **S 안정형** |
| 다이나믹 (LL) | 둘 다 평균보다 짧음 | 가게가 자주 바뀜 | **D 역동형** |
| 상권확장 (LH) · 상권축소 (HL) | 하나만 김 | 중간 | 보류 |

- 2025년에 잰 값이지만 가게들이 **여러 해 동안** 영업한 기간이 담겨 있어, 1년치 자료로도 오랜 흐름이 반영됩니다.
- 이름과 달리 상권확장·상권축소는 "커지고 있다·줄고 있다"는 뜻이 아닙니다. 그래서 '중간'으로 둡니다.
- 2025년 4개 분기 내내 같은 유형을 유지한 상권이 87.8%라서 기준으로 쓰기 안정적입니다.

**8유형:** LES 동네 단골형 · LED 생활 역동형 · LPS 동네 취향형 · LPD 취향 역동형 · VES 실속 유동형 · VED 유동 역동형 · VPS 목적 방문형 · VPD 방문 역동형.
D가 들어간 4개 이름은 박성은 STEP 5의 제안을 따랐고 팀 확정 전입니다. 예전 코드(LEG·LPG·VEG·VPG)를 넣으면 D 코드로 바꿉니다. 원래 이름과 아이템 예시는 `data/유형_정의.csv`에 있습니다.

## 추천 순서를 정하는 방법

1. 희망 업종의 **STEP 4 점수 대상 상권** 중 고른 축이 일치하는 곳만 남깁니다.
   - '상관없음'으로 둔 축은 거르지 않습니다.
   - 판정이 보류된 상권은 그 축을 고르면 빠집니다. 다른 유형으로 채우지 않습니다.
2. **STEP 4 종합 점수**로 줄을 세웁니다. 기본 가중치는 매출 30 · 경쟁 25 · 안정성 15 · 수요 30 [가정]입니다(화면에서 바꿀 수 있음).
3. 유형에 따라 **자동으로 바뀌는 것은 수요의 주 고객층 하나**입니다. L → 주민 중심, V → 유동인구 중심, 상관없음 → 세 값 평균.
4. **E/P와 S/D는 거르는 데만 쓰고 점수에 다시 더하지 않습니다.** 같은 정보를 두 번 반영하지 않기 위해서입니다. 근거 없는 유형별 가중치도 만들지 않았습니다.

## 이 추천으로 말할 수 없는 것

- **사용자의 금융 성향을 측정하지 않습니다.** 사용자가 세 축을 직접 고릅니다. 설문 문항은 팀이 따로 만들 예정입니다.
- **역동형이 유망하거나 성장한다는 뜻이 아닙니다.** 새 가게가 많이 들어오지만 일찍 닫는 가게도 많은 상권입니다.
- **L/V는 실제 손님의 출처가 아닙니다.** 주민·직장인 수의 비율이고 관광객·외부 방문객은 반영하지 못합니다.
- **E/P는 실제 가격대나 브랜드가 아닙니다.** 결제 1건당 금액의 상대 위치입니다.
- 추천이 맞았는지 확인할 정답 자료(실제 창업 성과·만족도)는 없습니다. 모든 관계는 상관이며 인과가 아닙니다.

## 팀이 정할 것

1. **S/D 정의:** 상권변화지표(이승희) / 분기 변동성(박성은) 중 하나
2. 'G 성장형 → D 역동형' 변경과 D가 들어간 4개 유형 이름
3. L/V·E/P 경계값(0.45/0.55, 45/55)
