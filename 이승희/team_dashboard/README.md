# SpotFit 팀 공유 대시보드 (claude.ai)

이 폴더는 팀원에게 공유한 PC용 대시보드의 **페이지 원본과 데이터 파일**입니다. 발표자료(`../presentation/`)의 그래프와 다이어그램도 이 데이터에서 만들었습니다.

- 대시보드 주소: https://claude.ai/artifact/WPf64cNXVm8t2VMkmjchHa
  - claude.ai 공유 링크입니다. 만든 사람이 Share 메뉴에서 공유를 켜야 다른 사람이 열 수 있습니다.
- 기준: 2025년 1~4분기 자료, 팀 공식 기준 v1 (2026-11-19 확정)
- 이 폴더의 파일은 2026-11-27에 올린 판(페이지 버전 16)과 같습니다.

## 금융 MBTI 보류 규칙 (페이지 코드와 같음)

- 사용자 설문이 애매하면(`상관없음`) 그 축은 거르지 않습니다.
- 사용자가 글자를 고른 축에서 상권 판정이 `보류(?)`이면 후보에서 뺍니다.
- 주 고객 축은 **주민 비율 = 상주 ÷ (상주 + 직장)** 으로, 0.55 초과는 L 생활형, 0.45 미만은 V 방문형, 그 사이는 보류입니다.

## 고칠 때

- 이 폴더의 파일을 고쳐도 claude.ai 대시보드는 바뀌지 않습니다. 대시보드는 claude.ai에 따로 올려야 합니다.
- 데이터를 만든 스크립트와 화면 검사용 스크립트는 작업 세션의 임시 폴더에만 있었습니다. 다시 만들 때는 위 표의 출처 파일에서 같은 열을 뽑으면 됩니다.
